화면에서 설명 문구를 걷어낸다 — 지시서·주석에만 남긴다

화면이 설명으로 덮여 지저분하다는 지적. 판단 근거는 코드 주석과 docs 에 그대로
두되 화면에서는 뺀다 — 주석은 고치는 사람이 읽고, 화면은 쓰는 사람이 본다.

남긴 것 — 설명이 아니라 «값을 담는 그릇» 이다:

    #ed-k-why       고른 기준개수의 근거(규칙번호·행 이름)
    #ed-zones       지정한 영역 목록
    #sub-picks      찍은 두 점의 좌표
    #sub-summary    추출 결과
    #dg-bore-legend 관경 근거 집계
    #dg-summary     설계 요약
    #mg-ready       결합 재료 유무
    #mg-summary     결합 결과·단계

기본 문구도 「아직 …않았습니다」 대신 「—」 로 줄였다. 값이 들어오면 어차피
덮이는 자리라 문장일 이유가 없다.

버튼에서 특허 부호를 뺐다 — 「결합 (S720 → S740)」 → 「결합」. 부호는 코드와
docs/module_f_integrated.md 가 갖는다. 화면에서 그것을 읽고 할 일이 갈리지
않는다.

■ 지우기 전에 참조부터 확인했다

`<p class="hint" id="…">` 중 셋(#sub-help · #sub-clean-help · #mg-drop-help)은
JS 가 토글하고 있었다. 그대로 지웠으면 그 화면을 열 때 ReferenceError 로 죽는다
— 정리 도구에 「지운 id 를 JS 가 아직 부르는가」 검사를 넣어 먼저 잡고, 참조를
없앤 뒤에 지웠다.
