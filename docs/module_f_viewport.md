# 모듈 F 줌 유지·사각 확대 (2026-09-16)

## 사용법

도면을 불러온 뒤 **01 도면 열기 → 사각 영역 확대**를 누르고 마우스 왼쪽 버튼으로 사각형을 그린다. 마우스를 놓으면 선택한 영역이 화면에 들어오도록 확대된다. 도면의 가로세로 비율은 유지한다. 화면 하단의 **사각 확대** 버튼은 다른 단계에서도 같은 기능을 제공한다.

한 번 확대하면 드래그 도구가 꺼진다. Esc는 취소이며, 8픽셀 미만의 실수 드래그는 확대하지 않는다. 사각 확대는 화면 카메라만 바꾼다. 설계면적, 헤드 선정, 배관망, 계산값을 변경하지 않는다.

## 시점 보존

- 도면 열기·찍기·손질·수리계산의 평면 보기·변환은 같은 CAD 시점을 공유한다. 자동 추출 완료와 미리보기 갱신도 시점을 초기화하지 않는다.
- 평면도·계통도·기계실은 각각의 시점을 기억한다.
- CAD 평면과 좌표계가 다른 아이소·정규화 설계도·통합도는 별도 시점을 기억한다. 해당 좌표계를 처음 열 때만 화면에 맞추고, CAD로 돌아오면 원래 확대 위치를 복구한다.
- 새 파일 업로드는 새 시점을 만든다. 명시적인 화면 맞춤·선택 항목 위치 찾기는 계속 화면을 이동한다.
- 창 크기를 바꾸면 확대 배율과 화면 중심을 보존한다. 기억은 현재 브라우저 페이지에 한정하며, 페이지 전체 새로고침 후까지 저장하지 않는다.

## 렌더링 변경

기존 `sy()`는 선 끝점마다 `getBoundingClientRect()`를 호출했다. 이를 창 크기 변경 시 한 번 갱신하는 값으로 바꿨다. 배경 도면·손질 배관의 선분은 변경되지 않은 배열별로 Path2D를 재사용하고, 화면 밖 경계 상자를 제외한다. 화면 양끝을 가로지르는 선은 양 끝점이 화면 밖이어도 유지한다. 선 두께와 점선 간격은 화면 픽셀 기준을 유지한다. 연속 그리기 요청은 animation frame마다 한 번으로 합친다.

## 검증 결과

- 브라우저·정적 자원 검사 **13건 통과**. 단계 왕복, 슬롯별 시점, 평면/아이소 왕복, 사각 확대가 선정 데이터에 영향을 주지 않음, 역방향/바깥쪽 드래그, Esc, 작은 드래그, 포인터 중심 휠 확대, 창 크기 변경, 선분 경계 처리 및 새 도면 초기화 검증.
- 기존 단계·슬롯·레이어·격자·아이소·읽기 관련 회귀 **91건 통과**. 합계 **104건**.
- 실제 5051에서 B1F DXF 별도 복사본 업로드 → 01 사각 확대 → 02 찍기 → 03 배관망 구성 → 04 수리계산 → 03 → 01을 검증했다. 모든 시점의 scale/ox/oy가 완전히 같았고 JavaScript 오류는 없었다. 헤드 6,895개, 간선 53,673개를 유지했다.

실제 B1F 표시 데이터(선분 132,905, 원 11,306, 호 15,677)에 같은 카메라와 브라우저 크기를 적용했다. 캔버스 한 장을 그린 뒤 픽셀 읽기로 완료를 기다린 12회 중앙값이다. 서버 계산이나 업로드 시간과는 별개다.
