# 수리계산 부속 표시·속성 카드

2026-09-20: 생성된 평면도 계산망의 평면/아이소 보기에서 모든 등록 부속을
빨간 짧은 점선으로 표시한다. 선택하지 않아도 유지하고, 선택하면 강조 굵기만
달라진다. 긴 빨간 점선은 기존 최원 경로다. 원본 CAD 밑그림/손질 진단 모드는
좌표계가 다르므로 계산망 부속을 겹쳐 그리지 않는다.

## 데이터와 판정

- 종류의 주인은 기존 부속 입력표다. 표시 단계에서 남은 간선 수로 티를
  엘보로 바꾸지 않는다. 기존 G 엔진은 `phys`(가지치기 전 물리 차수)를 사용한다.
- `routes/module_f/fitting_inspection.py`는 표를 변경하지 않는 표시 어댑터다.
  기존 부속은 하류 배관의 시작 절점 소속이다. 배관 양 끝에 같은 부속을
  중복 표시하지 않는다. 부속표의 한 물리 티에는 통과 배관별 손실 행이
  여럿일 수 있다. 카드는 각 행을 표시하고 겹친 형상은 한 번만 그린다.
- 직선 병합으로 노드가 없어진 직류티는 `interior_junctions`와 기존
  `board_cover`를 이용해 원본 경로의 상대 위치를 표시한다. 도면 역참조가
  없거나 후보 수가 맞지 않으면 **그리지 않고** 카드에 위치 미확인을 명시한다.
  일정 간격으로 티를 나열하는 대체 배치는 하지 않는다.
- 원본 연결 방향을 되찾으면 생략된 가지까지 표시한다. 원본 방향 불명,
  편집 후 원본과 불일치하면 현재 연결 방향만 표시한다. 다른 곳을 편집했다는
  이유로 전체 도면의 방향을 버리지 않는다. 기기표 추가 부속 등 형상 미확인은
  작은 위치 마름모로 표시하고, 고정 T/L 모양을 만들어내지 않는다.
- 편집기의 직접 추가 부속·밸브(기기표)와 판정 미확정 위치도 표시한다.
  미확정 종류는 마름모이며 티/엘보로 단정하지 않는다.

## 2026-09-20 판정 교정

- DXF 재료의 기본 범위는 저장된 `material_picks`의 **레이어×색 조합**이다.
  다른 레이어까지 같은 색으로 확장하지 않는다. 옛 프로젝트가 명시적으로
  필요로 할 때만 `material_scope: "color"`로 허용한다. 새 기본값은
  `"layer_color"`이며 레이어 이름을 코드에 하드코딩하지 않는다.
- 블록 유래 선도 같은 문을 통과한다. 선택 레이어 내부의 기존 헤드 틈
  연결 규칙은 유지한다. 선택된 레이어 자체에 비배관 선이 섞인 경우까지
  자동으로 의미를 확정하는 변경은 아니다.
- 가지치기 전 **실제 절점 ID의 연결**을 센다. 50mm 격자 칸 안에 있다는
  이유만으로 서로 다른 절점의 차수를 합산하지 않는다. 중복 간선도 한 번만 센다.
  서로 다른 CAD 절점 ID가 같은 위치·같은 방향의 선을 중복 표현한 경우도
  실제 포트는 한 개로 센다. 대명동의 4개 간선짜리 엘보에서 재현한 오류다.
- 수직 전개는 기존 가지의 재배치일 수 있다. 원본 차수에 수직 배관 수를
  더하지 않고 원본 차수와 현재 차수의 큰 값을 쓴다. 원본 역참조가 없다는
  이유만으로 수직 배관이라고 간주하지 않는다.
- 원본 티의 가지가 계산 범위에서 생략돼도 티라는 사실은 유지한다.
  직류/분류는 상류→절점→하류의 3D 방향으로 가른다. 기존 0/45/90도
  각도 스냅 경계는 유지하며, 수직 직진을 분류티로 취급하지 않는다.
- **4방향 이상을 크로스 또는 티 두 개로 자동 확정하지 않는다.** 실제 티의
  개수·배치/비접속 교차 확인이 필요하다는 미해결 항목을 남긴다. 중간에
  병합된 다중 접속도 미해결로 전달한다. 상류 미확정에서 분류티를 추측하지 않는다.
- 마커 반경은 도면 200mm를 표시 배율로 변환한 값과 인접 배관 표시 길이
  22% 중 작은 값이다(시각적 강조 범위, 실제 부속 치수 아님). 화면 픽셀로
  고정하지 않으므로 줌과 함께 확대·축소된다.
- 오래된 계산표를 여는 것만으로 저장된 손실을 몰래 고치지 않는다.
  변경된 추출/판정은 원본에서 다시 손질망을 열고 수리계산 표를 재생성할 때 적용된다.

실도면 추출 점검: 대명동 기존 선택을 사용해 원본에서 메모리상 재추출했을 때
헤드 130개 유지, 그래프 간선 3,143→2,542. 색상 자동 확장으로 들어오던
미선택 12개 묶음(249개 원시 선분)이 기본 재료에서 제외된다. 이것은 부속
정답률의 증명이 아니며, 최불리 선정·노드별 판단은 저장된 시작점과 대조해야 한다.

## 길이·손실

### B1F 헤드 접속점의 원본 분기 보존 (2026-09-20)

헤드 수직 전개에서 `attach_head_to_line`이 만드는 접속 절점은 기존 헤드의
원본 배관 접속 위치를 계승한다. 종전에는 이 절점에 `node_ref`가 없어,
최불리 선정에서 뒤쪽 배관이 사라진 관통 헤드 접속을 엘보로 판정했다.

- 전개 엔진은 `head_takeoffs[접속절점] = 원래헤드절점`을 기록한다.
- 서버 독립 `src/pipenet_converter/graph/fittings.py`가 이 명시적 대응으로
  부속 원본을 찾는다. 가까운 좌표/같은 격자에 있다는 이유로 대응시키지 않는다.
- **새로 분리한 헤드 접속만** 원본 평면 포트 수에 헤드 포트 하나를 더한다.
  기존 가지를 수직으로 재배치하는 경우에는 여전히 포트를 더하지 않는다.
  원본 배관이 한 방향뿐이면 엘보를 유지한다. 4포트 이상은 미확정으로 남긴다.
- 표시용 `fitting_node_ref`를 별도로 두어 헤드·직접편집기의 기존 안정 키인
  `node_ref`를 바꾸지 않는다. 원본에서 생략된 팔은 빨간 점선으로 표시할 뿐,
  계산 배관을 추가하거나 길이/연결을 바꾸지 않는다.

사용자가 생성한 B1F 작업의 읽기 전용 스냅샷을 별도 메모리에서 재현했다.
78개 노드의 표 좌표/표고, 77개 배관의 연결/길이/관경/재질/C값이 기존과
동일함을 확인했다. 해당 작업의 23, 30, 38, 46, 53, 59, 64, 76번이
엘보에서 분류티로 바뀌며, 25A 라이브러리 등가길이는 0.6→1.5m/개다.
그 외 부속 종류는 동일하다. 90번은 이 작업에 없으므로 확인하지 못했다.
이는 해당 작업의 회귀 검증이지 전체 도면의 부속/수리계산 승인 검증은 아니다.

`scripts/audit_module_f_live_fittings.py`는 세션의 조회 응답을 진단 파일로
저장하고 동일 선정 범위를 별도 메모리에서 재현한다. 서버 세션/손질 저장본은
변경하지 않으며, 수동 이음·삭제가 있는 작업은 임의로 재현하지 않고 멈춘다.
집중 테스트: `tests/test_module_f_head_takeoff_fittings.py`.

- 배관의 실제 길이, 부속별 등가길이(m/개), 개수, 항목 합, 배관 부속 합을 구분한다.
- 부속별 값은 기존 `resolve_eq_len`과 라이브러리/직접 입력 이력을 읽는다.
  배관 합계는 입력표의 저장값이다. 기기표의 값은 별도 기기 손실이다.
- **직류티/직류 크로스의 0 m는 기존 엔진의 미계상 규칙**이다. 카드에
  검토 대상으로 명시한다. 수치 규칙은 이번 판정 교정에서도 변경하지 않는다.
- 없는 라이브러리 값은 미확정으로 표시하며 0으로 바꾸지 않는다.
- 저장 합계와 종류별 근거를 읽는 기능이다. 이 기능이 부속 규격/마찰 기준의
  적합성을 승인하거나, 기존 계산 입력의 정확성을 보증하는 것은 아니다.

## 화면

- `static/module_f_inspection.js`: 상시 형상, 형상 클릭 판정, 부속 카드.
- 직접 편집 모드에서 숨겨져 있던 `dg-ins` 카드를 다시 표시한다.
- XYZ 조작은 유지한다. 카드 위치는 네 모서리 중 절점/선택 핸들을 덜 가리는
  위치를 고른다. 원본 좌표, 배관 길이, 손실을 수정하지 않는다.
- 별도 노드가 없는 중간 부속 기호를 클릭하면 소속 배관과 부속 목록을 연다.
- 기존 직접 편집/값 수정 기능과 저장 이력은 그대로 유지한다.

검증: `test_module_f_fitting_inspection.py`,
`test_module_f_fitting_inspection_browser.py` 및 기존 수리계산/편집/가지치기/
변환 회귀 테스트. 브라우저 테스트는 격리된 표본이며 사용자 세션을 변경하지 않는다.
