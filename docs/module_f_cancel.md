# 모듈 F Working 중지 (2026-09-16)

모든 공통 Working 상자의 오른쪽 위에 `×`(현재 작업 중지)를 추가했다. 파일 압축·업로드, 도면 읽기, 찍기·손질, 배관망 추출, 표 확정, 전체 진단, 변환·결합에 같은 작업 번호를 사용한다.

## 동작

- 클릭하면 진행 스트림과 브라우저 압축·전송을 중단하고 서버에도 중지를 요청한다.
- 계산 중인 Python 작업은 취소 체크 지점에서 빠져나온다. 대기열의 작업은 다른 작업이 끝나기를 기다리지 않고 취소된다.
- 서버가 작업 종료를 확인한 뒤 Working을 닫는다. 화면만 닫고 계산을 남겨두지 않는다.
- 취소된 작업의 완료 콜백과 다음 자동 단계는 실행하지 않는다. 늦게 도착한 동일 작업 번호의 요청도 거부한다.
- 중간에 바뀐 세션 상태는 작업 직전 상태로 복구한다. 취소 후 확정된 서버 상태를 다시 읽으며, 재실행할 수 있다.
- 다른 세션의 작업과 이미 시작한 새 작업은 오래된 중지 요청으로 취소하지 않는다.

## 중지 경계

스레드 강제 종료나 서버 종료는 사용하지 않는다. 열려 있는 출력 파일의 쓰기·저장 함수는 파일을 닫은 뒤 중지한다. 네이티브 라이브러리 호출 및 OS 입출력은 Python으로 돌아온 뒤 중지된다. 그동안에는 **중지 중…**으로 표시한다. 중지 전에 이미 끝난 파일 저장은 되돌리지 않는다.

현재 서버(Python 3.13)는 중지 요청이 있을 때만 `sys.monitoring`의 LINE 검사를 켜며, 종료 후 해제한다. Python 3.11 또는 모니터링 슬롯을 사용할 수 없는 환경은 해당 작업 스레드의 trace 검사로 대체한다. API 근거: [Python sys.monitoring](https://docs.python.org/3/library/sys.monitoring.html).

세션 복구용 사본에서 변경되지 않는 DXF 원본 형상·공간 인덱스는 공유하고 편집 상태를 복사한다. 현재 계산 스레드가 멈추기 전에는 중지 완료로 처리하지 않는다.
