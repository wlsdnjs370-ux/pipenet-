# 회사 스프링클러 헤드 감지 규칙 — PPT 26~36쪽

## 완료 범위

제공된 PPT의 원본 그림, 슬라이드 텍스트, 그림 자르기 위치, 35쪽의
PowerPoint 삼각형 도형을 대조하여 **평면도 6종 + 단면도 2종**을 별도
프로필 `company_260404`로 등록했다. 신경망을 재학습한 것이 아니라,
판정 근거를 확인할 수 있는 결정론적 기하 규칙이다.

**국소 기호 분류기와 Module F 찍기 → 배관망 구성 파이프라인 연결을 구현했다.**
찍기의 ‘헤드 감지 규칙’에서 ‘회사 표준 (PPT 26~36쪽)’을 명시적으로 선택한다.
기존에 선택한 헤드 후보와 대상 레이어 범위에서 원본 DXF 기하를 대조한다.
DXF 전체에서 임의의 기호를 새로 찾는 기능은 아니며, PPT와 다른 기존 범례에
이 프로필을 자동 적용하지 않는다. 순수 자동 추출 경로에는 연결하지 않았다.

영역 지정 사용법과 연결 범위: [회사 규칙 연결 및 자유곡선 영역](module_f_company_rules_and_lasso.md).

26쪽의 원본 그림을 위에서 아래로 나열한 순서이다. PPT **표 행 순서**는

그림 원본의 행 순서와 다르다. 자르기 좌표와 표 위치를 대조하여 매핑했다.

원본 범례 그림: `data/company_head_reference_260404/image37.png`.
36쪽의 녹색 범례도 함께 확인했다. 색상은 독립적인 방향/온도 판정 조건이 아니다.

## 단면도와 설치 예시

- 27쪽: 배관 위, 위를 향한 채워진 삼각형 → 상향식.
- 28쪽: 배관을 기준으로 상·하향 기호를 각각 표시.
- 29쪽: 배관 아래, 아래를 향한 채워진 삼각형 → 하향식.
- 30쪽: 천장 공간에 상·하향을 함께 설치한 예시.
- 31~34쪽: 평면도 기호와 설치 방식의 대응. 회전된 오프셋 원/X도 같은 기호다.
- 35쪽: 측벽식 적용 예와 드라이펜던트 설명. 삼각형만 보고 건식·반응속도까지 확정하지 않는다.
- 36쪽: 일반 72℃/주방 고온형 103℃ 설명. 방 이름만으로 헤드 온도를 자동 설정하지 않는다.

단면도에서는 명시적인 ‘도면 위 방향’과 배관 연결 목선을 함께 확인한다.
단면 삼각형의 채움으로 103℃를 추정하지 않는다. 온도는 별도 미지정으로 남긴다.
상·하향 두 기호는 각각의 헤드이며, 평면도에서 이미 센 헤드와 단순 합산하지 않는다.
‘천장 속 2M’ 등의 자료 설명은 설치 예시로 보관하며 법규/설계 자동 판정에는 사용하지 않는다.

## 안전한 감지 조건

1. 회사 프로필, 도면 종류(plan/section), 헤드 대상 레이어를 명시한다.
2. DXF 어댑터가 본체 원/삼각형, 부속 표시선/호, 실제 배관 접속점을 구분한다.
3. 본체 반지름으로 정규화하여 회전·축척·좌표 이동에 독립적으로 판정한다.
4. 평면도 오프셋 기호는 목선, 횡선, 양옆 표시선과 반원 방향까지 확인한다.
5. ‘속이 참’은 HATCH/SOLID/TRACE의 **면 채움** 근거로만 정한다.
   현재 어댑터는 폭 있는 폴리라인과 패턴 HATCH를 불확실 근거로 취급한다.
   선색·선굵기·저해상도 화면 때문에 원이 까맣게 보이는 것은 근거가 아니다.
6. 완전한 도형/채움 확인이 없거나 명시적인 종류·온도와 충돌하면 `review`.
   선택하지 않은 레이어는 `excluded`; 정확히 하나의 규칙을 충족할 때만 `matched`.
7. X, 반원, 표시선은 기호 장식이다. 분류 결과에 배관 간선이나 부속류를 생성하지 않는다.
   심볼 목선의 그림상 길이도 배관 길이에 더하지 않는다.
8. 수량 2는 **상·하향 한 쌍이라는 의미**이다. 실제 Z·연결·작동 헤드수·유량은
   별도 변환/설계 단계에서 정해야 한다. 본 분류기는 이를 자동 생성하지 않는다.

분류기 자체는 실제 좌표, 배관 길이, 압력, K값, 재질, 작동 유량을 변경하지 않는다.
확정된 상·하향 분류는 기존 후속 변환 단계의 헤드 종류 입력으로 사용된다.
명시된 수동 값에 충돌하면 덮어쓰지 않고 판정 후보와 충돌 사유만 반환한다.

## 미지원 및 검토 대상

- 그림 파일/OCR로 직접 헤드를 찾는 기능이 아니다. PPT 사진은 학습 가중치로 쓰지 않는다.
- 본체 후보 추출은 기존 DXF 추출부를 사용한다. 원/삼각형 후보가 만들어지지 않는
  HATCH 전용 본체는 새로 탐색하지 않는다. 비균일 축척, 부분 채움, 분절된 목선,
  누락된 범례는 현재 자동 확정하지 않는다.
- 원·호가 추가된 다른 회사/구형 기호는 기본 상향식으로 간주하지 않는다.
- 손질의 ‘회사 헤드 감지 결과’에서 확정/검토 상태, 방향, 온도, 좌표와 근거를 확인한다.
  측벽식은 속성 근거에 보존하되, 상향/하향식으로 임의 변환하지 않는다.
  현재 변환 모델에 측벽식 연결 높이/방향이 없으므로 해당 후보는 계산 변환을 차단하고
  검토 사유를 반환한다. 측벽식의 완전한 수리 모델은 별도 구현이 필요하다.
- 실물 MF-106 도면 전체의 검출 정답률은 검증하지 않았다.

서버 반영 후에는 도면을 다시 열고 찍기에서 회사 프로필을 선택하여 배관망을
다시 구성해야 한다. 기존 손질 결과에 새 분류를 소급 적용하지 않는다.
