# Module H — 지정 영역 전체 헤드 추출

## 사용자 규칙

- 03 배관 네트워크 정의에서 기준개수 입력·프리셋·먼 순서 K개 선정은 사용하지 않는다.
- 급수원을 지정하고 사각형 또는 펜 영역을 그린 뒤 **영역 배관망 추출**을 실행한다.
- 대상은 02 객체 정의를 거친 헤드의 중심점이다. 영역 경계 포함, 복수 영역은 합집합이다.
- 영역 미지정은 전체 도면으로 해석하지 않는다. 빈 영역도 추출하지 않는다.
- 영역은 헤드를 선택하는 범위이며 도면 잘라내기가 아니다. 급수원과 연결하는 관로가 영역 밖으로 나가더라도 유지한다. 02의 도면 잘라내기는 별도 기능이다.
- 영역 안 미연결·미지정 헤드는 좌표와 사유를 제시하며 중단한다. 밖의 헤드로 대체하거나 조용히 제외하지 않는다.
- 기존 물리 헤드 대표 규칙을 유지한다. 같은 좌표의 동일 종류 CAD 기호는 중복으로 보고 개수를 안내한다. 종류가 서로 다르면 검토 오류로 남긴다. 상하향식 기호는 출력에서 두 노즐이다.
- 트리 경로와 루프·그리드 연결 보존 규칙은 유지한다. **선정용 K**와 **트리 관경 산정용 전체 담당 헤드 수**는 별개이며 후자는 변경하지 않는다.
- 이 작업은 수리계산 또는 법규 적합성의 확정이 아니다. 관경 역산·속성 정책 통합은 별도 작업이다.

## 구현 경계

`src/pipenet_converter/graph/area_selection.py`는 Flask 없이 영역과 FlowTree를 받아 후보·대표·중복·미연결 목록을 만든다. 거리 순위를 잘라내는 함수와 K 매개변수가 없다.

`routes/module_f/area_selection.py`는 이 결과를 기존 F/H 편집 상태·경로·전개 계약으로 연결한다. H 요청은 `selection_mode=area_all`을 명시한다. F 기본값 `ranked_k`는 유지한다.

H의 오래된 K 컨트롤 ID는 공용 JS 초기화 호환용으로 비활성/비표시 상태로만 남는다. 프리셋 요청을 하지 않으며 K와 도면 장 값은 H 선정·입력표 요청에서 제거한다. 영역 전체 모드는 장 선택값으로 헤드를 추가로 자르지 않는다.

표 생성은 승인된 헤드 ID 집합을 직접 전개한다. 전체/200개 제한에 의한 재선정은 없다. 내부 `k` 호환 메타데이터는 **선정 결과의 개수**이며 사용자 입력이 아니다. 표에서는 ‘영역 내 전체 헤드 수’로 표시한다. 전개 후 노즐 수가 달라도 정상 완료하지 않는다.

영역 변경·급수원 변경·배관 편집·헤드 변경 시 재추출이 필요하다. 입력표·SDF의 기존 신선도 검사에 영역 정책 검증을 추가했다. 저장된 영역은 기존 `selection_zones` 형식을 그대로 사용하며 이전 K는 재사용하지 않는다.

H는 구형 K 기반 자동 추출의 신규 진입을 표시하지 않는다. 기존 자동 완료 세션은 ‘배관 네트워크 정의로 이동’으로 인식 결과를 이어받을 수 있다. 완료 전 자동 세션은 도면 업로드부터 H의 영역 경로를 시작한다. F 자동 경로는 변경하지 않는다.

## 검증

- 순수 함수: 영역 필수, 사각형/오목한 펜 영역, 경계, 겹치는 영역 합집합, 중복 기호, 미연결, 259개 선택.
- HTTP: 트리/루프/그리드 전량 선정과 입력표, 영역 밖 급수 경로, 211개 선택 및 설정 전달, 잘못된 영역/연결/변경 상태 거절.
- SDF: 루프/그리드 테스트망 파일 재읽기 후 헤드 수·고리 보존. 211개 헤드의 선택 → 입력표 → SDF 재읽기에서도 전량 유지. 실제 PIPENET UI 검증을 의미하지 않는다.
- 세션: 격리된 작업 결과 게시, 영역 저장/재읽기, 기존 F K 선정 회귀.
- 브라우저: 기준개수 비표시/비활성, 프리셋 요청 없음, 실제 H 요청에서 K 제거, 영역 추출·해제 및 진행 UI.

운영 데이터 자동 변경/원본 DXF 삭제 없음. Python 변경 배포는 사용자 재시작 승인 후 수행한다.
정적 파일만 먼저 갱신되어도 구형 서버의 K 기본값으로 실행되지 않도록 H의 정책 버전 확인 후에만 추출·입력표 생성 요청을 보낸다.
