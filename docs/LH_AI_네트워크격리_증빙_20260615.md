## 2. "AI" 기능의 실체 — 로컬 내장 모델

본 프로그램의 "AI"로 표기되는 기능은 다음 세 가지이며, 모두 사용자 PC 내부에서 실행된다.

| 구성요소 | 기술 | 실행 위치 | 외부 통신 |
|---|---|---|---|
| 스프링클러 헤드 인식 | 학습된 YOLO 가중치(`best.pt`) + 템플릿 매칭 | 로컬 CPU/GPU | 없음 |
| 배관망 추론(GNN 파이프라인) | `fire-dxf2sdf` 로컬 서브프로세스 | 로컬 CPU | 없음 |
| 수리계산·그래프 정제 | 결정론적 알고리즘(numpy/scipy/networkx) | 로컬 CPU | 없음 |

모든 모델 가중치는 디스크상의 로컬 파일이며, 추론 시 외부 서비스를 호출하지 않는다.

## 3. 검증 방법론 (재현 가능)

전체 소스 트리에 대해 다음 4종 정적 분석을 수행하였다. 모든 명령은 프로젝트 루트에서 재현 가능하다.

1. **의존성 명세 검사** — `requirements.txt`에 AI-API 클라이언트 패키지 존재 여부
2. **AI SDK import 스캔** — `openai`, `anthropic`, `google.generativeai`, `cohere`, `langchain` 등
3. **외부 호출 프리미티브 스캔** — `requests`, `httpx`, `urllib`, 외부 소켓 연결
4. **외부 URL/API 키 스캔** — `api.openai.com`, `generativelanguage.googleapis.com`, `*_API_KEY` 등

검증 대상은 운영 코드(`대조 서버.py`, `serve.py`, `ai_vision.py`, `head_detector.py` 및 파이프라인 모듈)이다. 벤더 번들(`K-Fire_Solver/_internal`), 가상환경(`.venv`), 백업(`backups/`), 스냅샷(`exports/`)은 운영에 포함되지 않으므로 §6에서 별도로 다룬다.

## 4. 정량 검증 결과

### 4.1 의존성 명세 (`requirements.txt`)

운영 서버의 직접 의존성은 10개이며, **AI-API 클라이언트 패키지는 0개**이다.

```
flask==3.1.3          ezdxf==1.4.3         pypdf==5.4.0
openpyxl==3.1.5       matplotlib==3.10.7   pandas==2.3.3
networkx==3.6.1       PyYAML==6.0.3        waitress==3.0.2
python-dotenv==1.0.1
```

- `openai` / `anthropic` / `google-generativeai` / `cohere` / `langchain` / `litellm` → **명세에 없음 = 설치되지 않음** (호출 시 `ImportError`로 즉시 실패)
- AI 연산용 패키지는 `torch` + `ultralytics`(YOLO)이며, 이는 **로컬 추론 라이브러리**로 네트워크를 사용하지 않는다.

### 4.2 외부 호출 프리미티브 스캔

운영 코드 전체에서 외부 네트워크 호출(`requests`/`httpx`/`urllib`/외부 소켓)은 **0건**이다. 유일하게 존재하는 네트워크 코드는 내부 서브프로세스 기동을 위한 **localhost(127.0.0.1) 연결**뿐이다.

```
대조 서버.py:395    with socket.create_connection(("127.0.0.1", port), timeout=0.5):
```

→ 대상 주소가 `127.0.0.1`(자기 자신)로 고정되어 있어, 외부 호스트로의 연결이 코드상 불가능하다.

### 4.3 "AI" 모듈의 로컬성 검증

운영 서버가 실제로 로드하는 AI 모듈은 루트의 `ai_vision.py`이다.

```
대조 서버.py:4567   from ai_vision import get_cached_ai_vision_extractor
```

해당 모듈의 의존성은 로컬 객체인식기뿐이며, 외부 SDK·네트워크 코드가 전혀 없다.

```
ai_vision.py:8      from head_detector import TriangleHeadDetector
```

`head_detector.py`의 import 역시 로컬 연산 라이브러리로 한정된다.

```
head_detector.py    import cv2 / import numpy / import torch / from ultralytics import YOLO
```

→ `cv2`(영상처리), `numpy`(수치연산), `torch`+`ultralytics`(로컬 YOLO 추론)뿐으로, **외부 API 클라이언트가 없다.** 추론은 로컬 가중치 파일(`best.pt`)을 사용하여 사용자 PC에서 수행된다.

### 4.4 외부 AI 엔드포인트·API 키 스캔

운영 코드(`대조 서버.py`, `serve.py`, `ai_vision.py`, `head_detector.py`)에서 다음 항목 **전부 0건**:

- `api.openai.com`, `api.anthropic.com`, `generativelanguage.googleapis.com` 등 AI 엔드포인트
- `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `GOOGLE_API_KEY` 등 API 키 참조
- `gpt-4`, `claude-`, `gemini-` 등 외부 모델 식별자

## 6. 운영 비포함 항목에 대한 명시 (오해 방지)

소스 트리에는 운영에 **포함되지 않는** 참고/백업 파일이 존재한다. 이들은 import 경로 밖이거나 의존성이 설치되지 않아 운영 서버에서 실행될 수 없으나, 투명성을 위해 명시한다.

| 항목 | 내용 | 운영 포함 여부 | 근거 |
|---|---|---|---|
| `tmp_ai_files/ai_vision.py` | Claude API 호출 코드 포함(`import anthropic`, line 485) | **미포함** | 운영 import는 루트 `ai_vision.py`로 해석됨. `anthropic` 패키지 미설치 → 실행 시 `ImportError` |
| `backups/sprinkler_ai_agent_server_source_2026-04-27/` | 과거 별개 시제품. OpenAI/Gemini 호출 코드 포함 | **미포함** | 백업 디렉토리. 운영 서버가 import·실행하지 않음 |

> **권고:** LH 제출용 배포 패키지에서는 위 두 항목을 제외하여 혼선 가능성을 원천 차단한다.

## 7. 외부 네트워크 연결 완전 제거 조치

AI/데이터 측면의 외부 연결은 §4에서 입증된 바와 같이 부재하나, **브라우저 화면 렌더링용 정적 자산(폰트·CSS·JS 라이브러리)** 일부가 외부 CDN에서 로드되고 있었다. 이는 AI나 데이터 전송과 무관한 단방향 다운로드이나, "외부 연결 0" 주장을 네트워크 레벨에서 완전무결하게 만들기 위해 로컬화한다.

| 외부 자산 | 출처(조치 전) | 조치 |
|---|---|---|
| Inter / JetBrains Mono 폰트 | `fonts.googleapis.com`, `fonts.gstatic.com` | `static/vendor/` 로컬 호스팅 |
| Tailwind CSS | `cdn.tailwindcss.com` | 로컬 호스팅 |
| dxf-parser | `cdn.jsdelivr.net` | 로컬 호스팅 |
| three.js / OrbitControls | `cdn.jsdelivr.net` | 로컬 호스팅 |
| ultralytics 익명 사용통계 | 외부 분석 서버(기본값) | 텔레메트리 비활성화 고정 |

조치 완료 후 본 프로그램은 정상 동작 중 **외부 호스트로 어떠한 연결도 발생시키지 않는다.** (인바운드 cloudflared 터널은 외부→내부 단방향 접속 경로이며, 내부에서 외부로 데이터를 송신하지 않는다.)

**조치 상태: 완료 (2026-06-15).**

- 자산 로컬화: `scripts/localize_cdn_assets.py` 실행 → `static/vendor/`에 JS 5종 + 통합 폰트 CSS + woff2 13종 고정.
- 템플릿 교체: `scripts/rewrite_cdn_links.py` 실행 → 운영(domain-slim) 템플릿 13건, 로컬(main) 18건 교체.
- ultralytics 텔레메트리: `settings.sync = False` 영구 저장(`%APPDATA%\Ultralytics\settings.json`) + `head_detector.py` 로드 시 재확인 가드 추가.

**검증 결과 (임시 서버 기동 후 실측):**

| 검증 | 결과 |
|---|---|
| 운영 템플릿 내 외부 CDN 참조 | **0건** (`grep` 전수) |

## 9. 종합 결론

1. 본 프로그램의 "AI"는 **사전 학습·내장된 로컬 모델**이며, 추론은 전적으로 사용자 PC 내부에서 수행된다.
2. 외부 AI/LLM API(Gemini/Claude/GPT)로 도면·계산·기밀 데이터가 전송되는 경로는 **소스코드 수준에서 존재하지 않는다.**
3. 의존성 명세에 AI-API 클라이언트가 **없으며**, 설사 비운영 참고파일이 그러한 코드를 포함하더라도 해당 라이브러리가 설치되지 않아 **실행 자체가 불가능**하다.
4. AI/데이터와 무관한 정적 자산의 외부 로드까지 제거하여, 조치 후 본 프로그램은 **외부로의 능동적 네트워크 연결이 0**이다.

따라서 사내 기밀의 외부 유출 우려는 본 프로그램의 구조상 해당하지 않는다.
