# 모듈 F 계통도 경로와 밑그림 분리

2026-09-17

## 확인한 원인

공용 `stitch_riser_and_heads`는 계통도 절점을 같은 X의 세로 막대로 재배치했다.
막대 길이는 실제 표고 대신 평면도 크기와 기계실 표시 여백으로 정했다.
표고가 같은 10m 수평 경로도 16m 세로 표시로 바뀌는 경우를 재현했다.
이렇게 방향을 잃은 SDF의 Position으로 KFP를 만들면 원래 방향을 복원할 수 없다.

별도로 계통도 추출은 층 정보가 없을 때 도면 Y차를 높이로 추정한다.
같은 층의 기계실 평면이 함께 그려진 도면에서는 이 추정이 맞지 않을 수 있다.

## 변경

- 밑그림의 수직 정렬, 흰 점선 테두리, 회색 겹침 경계를 유지한다.
  밑그림 변환은 배관망이나 계산값을 변경하지 않는다.
- F에서 실제 DXF로 추출한 계통도는 원래 선택 경로의 방향과 지정 길이,
  표고로 배치한다. 수평 길이는 `sqrt(length²-높이차²)`로 구한다.
  순수 수직관만 XY가 같은 자리에 놓이며 아이소 화면에서 수직으로 보인다.
- 평면도 알람밸브를 공통 접속점으로 삼고 기계실도 새 접속점에 붙인다.
  미리보기와 SDF 아이소는 같은 투영을 사용한다. KFP는 투영 전 좌표를 쓴다.
- `계통도 표고 기준`에 `같은 층 · 표고차 0으로 시작`을 추가했다.
  선택 시 자동 추정 표고를 0으로 시작하고 원래 그래프에서 측정한 길이를 쓴다.
  종전 추정값은 추출 결과에 보존한다. 실제 높이차가 있는 부분은 기존 통합
  노드 속성 편집으로 입력한다. 같은 층이라는 이유만으로 국소 높이차가
  없다는 것을 자동 판정하지는 않는다.
- 층간 도면은 기존 표고 추정을 유지한다. 도면의 수평 방향은 선택 경로를
  표현하며, 방위 정보 없이 실제 건물 방위를 추정한다는 의미는 아니다.
- 기존 템플릿 및 다른 모듈의 공용 배치 함수는 변경하지 않았다.
- 루프의 길이/방향이 모순되면 명시적인 오류를 낸다. 연결을 삭제하거나
  길이를 늘려 맞추지 않는다.

## 검증과 사용

밑그림 단독 13건, 관련 계산·추출·통합 166건, 추가 기계실 정렬 및 실제 브라우저
검사를 수행했다(중복 제외 181건 통과). 수평/수직 혼합, 급수방식 독립성, 같은 층 추출, KFP 길이·연결,
밑그림 무변경, 기계실 접속 및 UI 선택 전달을 포함한다.

기존 통합 파일에는 원래 경로 방향이 이미 지워져 있으므로 새 설정으로 계통도를
다시 추출한 다음 통합·출력해야 한다. B1F의 같은 층 경로는 `같은 층`을 선택하고,
실제 높이차가 있으면 노드에서 수정한다. 이전 다운로드 파일은 자동으로 바뀌지 않는다.
