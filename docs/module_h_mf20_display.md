# MF20 평면도 표시 누락 수정

## 원인과 변경

- 평면도 원본 `world.texts`는 읽었으나 웹 표시 응답에 포함되지 않았다. Module H 업로드에 한해 현재 world의 문자를 전달한다. 숫자는 0도, 원래 좌표·높이를 사용하며 계산망에 새 간선을 만들지 않는다. 영역 자르기도 같은 world의 문자를 사용한다.
- 기존 스트리밍 파서가 DXF extrusion(210/220/230)을 버려 -Z OCS의 원호 및 INSERT를 반대편 X 좌표에 배치했다. OCS를 부모 INSERT 변환 전에 적용하고 큰 원호의 sweep를 유지한다. LINE/MTEXT의 WCS에는 중복 적용하지 않는다.
- H 평면도의 원본 색상은 표준 ACI를 사용한다. 예컨대 80번은 기존 임의의 짙은 녹색이 아닌 CAD 표준 밝은 녹색이다. 선택 강조 색은 변경하지 않는다.
- 준비 world/편집 캐시는 좌표 변환 코드 변경을 감지하여 이전 좌표를 재사용하지 않는다. 원본 DXF와 사용자 저장 스펙은 삭제하거나 덮지 않는다.

## 실제 파일 검증

`python -X utf8 -m scripts.audit_mf20_display`는 MF20 원본을 읽기만 하고 별도 `outputs/mf20_display_review/`에 검토 자료를 남긴다.

- 선분 6,655 / 원 301 / 원호 539: 객체 수 유지
- 표시 문자 396개, 예시의 두 `50` 포함
- 예시 영역 X=195000~207000, Y=3018000~3031000 mm: 기존 캐시의 원호 0개 → 수정 후 30개
- 반대편 X<0에 놓이던 원호 103개 → 0개
- 원본 내 -Z 표기: INSERT 231개, ARC 39개. LINE 3,833개는 WCS이므로 반전하지 않는다.

## 범위와 한계

이번 수정은 XY 평면의 ±Z OCS를 지원한다. 기울어진 OCS를 원으로 잘못 투영하지 않고 명시적 오류를 낸다. 비균일 확대 INSERT/임의 3D 투영, CAD 폰트 파일·선종류의 완전한 재현은 별도 범위다. 문자 표시와 자동 관경 추적 판정은 분리되어 있으며 이번 수정은 관경 값을 임의로 채우지 않는다.

서버 재시작 후 같은 도면을 다시 열어야 새로운 좌표로 읽힌다. 이미 계산된 그래프는 자동으로 재작성하지 않는다.
