# 수리계산 입력 격차 — 수작업본 대비 자동본

FNCADnet 작업지시서(모듈 A) §6 산출물. 과제마다 대조기를 돌려 총유량 일치율을 기록한다.

## 대조기

```
python -m calibration.compare_reports <수작업.docx> <자동.docx> [--json OUT] [--md OUT]
```

기준 자료 경로는 `PIPENET_REF_MANUAL_DOCX` / `PIPENET_REF_AUTO_DOCX` 환경변수로 지정한다.
(`tests/test_compare_reports.py` 도 같은 변수를 본다. 미지정 시 실물 대조 테스트는 skip.)

## T0 에서 확인된 지시서 §2 와의 차이

지시서 §2 표는 근거 자료이므로 수정하지 않는다. 대조기가 실제로 읽은 값과
표기가 갈리는 지점만 여기에 남긴다.

1. **표고 합계의 집계 기준이 서로 다름.** §2 의 "총 하강 75.0 m → 53.4 m" 에서
   수작업 75.0 은 0.5 m 이상 하강만, 자동 53.4 는 전체 하강을 더한 값이다.
   같은 기준으로 맞추면 수작업 -78.0 / -75.0, 자동 -53.4 / -53.2 다.
   수작업본의 -0.1 m 급 국소 하강 약 30건(헤드 니플·FX 드롭 추정)이 차이의 전부다.
2. **"30개 중 19개 최소압 미달" → 실측 18개.** NOZZLE CONFIGURATION 의 최소압과
   FLOW THROUGH NOZZLES 의 입구압을 노즐별로 대조한 결과가 18개다.
   % Deviation 이 음수인 노즐 수도 18개로 같다.
3. **자동본 관로 136개 중 21개는 문자 라벨**(`M1/0`~`M17/0`, `R1/0`~`R4/0`)이다.
   숫자 라벨만 읽는 기존 파서(`core/pipenet_validator.py`)로는 115개만 잡혀
   기계실·라이저 구간이 통째로 누락된다. 대조기는 문자 라벨을 허용한다.
4. **PIPE FITTINGS 의 Equivalent Length 는 개당 값**이다. `2 x 2  4.267` 은
   90° 엘보 2개 × 4.267 m = 8.534 m 다. 개수를 곱하지 않으면 수작업 합계가
   253.54 m 가 아니라 236.57 m 로 나온다.

## 아직 사람이 정해야 하는 것 (지시서 §5)

에이전트가 임의로 정하지 않는다. 답이 나올 때까지 관련 지표는 `None`(미확정)으로 둔다.

1. 부속 등가길이 환산표 — **결정됨(T7 에서 구현)**: NFPA 기본과 국내 KS 를 둘 다 등재하고
   화면에서 고른다. 어느 쪽도 자동 선택하지 않는다.
2. 알람밸브 주변 표준 밸브 구성(게이트/체크/버터플라이 각 몇 개) — 미확정
3. 상향식 헤드 촛대 길이, 지하주차장 보 하단 하향값 — 미확정

FX 규격 기본값도 사람 판단이다. 지시서 T3 은 기본값을 한백표준으로 교체하라고 했으나,
타사 도면 대조가 잦아 **기본값은 "평균" 유지**하고 한백표준은 선택 항목으로만 등재했다.
