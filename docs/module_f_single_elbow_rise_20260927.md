# Module F — 단독 호 엘보의 수직 접속

## 적용 해석

사용자가 B1F 컨셉2 화면의 기존 82번 위치를 0.5 m 수직 상승 접속으로 확인했다.
원본 식별자는 `N27760`이며, 화면 번호는 재생성 과정에서 달라질 수 있다.
0.5 m는 도면에서 실측한 높이가 아니라 기존 `branch_rise_m` 입력값이다.

기존 루프·그리드 변환은 두 포트 호를 짝을 이룬 우회 구간일 때만 전개했다.
이번 수정에서는 열린 방향 하나와 닫힌 방향 하나가 확인된 단독 호도
`elbow_rise`로 기록하고 위·아래 절점을 분리한다. 같은 XY 좌표를 갖는
두 절점 사이에 설정 높이만큼 실제 세로관을 생성한다. 양 끝의 부속은
수평–수직 접속 벡터로 다시 판정하며, 단순한 화면 기호 이동이 아니다.

## 유지하는 안전 조건

- 원본 연결의 포트 방향으로 높이를 결정한다. 루프의 BFS 참조 화살표를
  실제 유향이나 상승 방향으로 해석하지 않는다.
- 종전의 짝 우회 구간 판정은 보고용으로 유지한다. 단독 기호 처리를 막는
  필수 조건으로만 사용하지 않는다.
- 모든 수평 연결 성분의 표고 조건을 함께 검사한다. 다른 복귀 경로와
  충돌하면 원본 연결·기준 표고를 유지하고 높이 미확정으로 남긴다.
- 호 없는 평면 엘보, 포트가 모호한 기호에 세로관을 추측해서 넣지 않는다.
- 트리 변환 경로와 저장된 손질 데이터는 수정하지 않는다.
- 루프·그리드 관경과 수리계산의 검토용/미확정 표시는 계속 유지한다.

## 검증 결과

선택된 13개 헤드의 실제 B1F 원본을 루프·그리드 양쪽으로 재현했다.

- 기존 82번과 동일 유형 2곳(`N27699`, `N27711`)에 각각 0.5 m 세로관 생성.
- 위·아래 절점의 XY 일치, 표고차 0.5 m, 실제 관 길이 0.5 m 확인.
- 화면 투영에서 위·아래 절점이 수직으로 분리되고, 양 끝 엘보 속성에
  각각 65A 기준 등가길이 1.8 m가 표시됨을 검사.
- SDF를 다시 읽어 세로관의 길이 0.5 m와 절대 표고차 0.5 m 확인.
- 215절점 / 218배관 / 13헤드 / 독립 루프 4개. 루프 연결 수는 불변.
- 실제 배관 총길이 199.537850017 → 201.037850017 m: 세로관 3개의 1.5 m만 증가.
- 남은 부속 검토 대상은 겹친 호 기호 `N19624`(재현 표 71번) 한 곳.
- 전체망 KFP: 2,164절점 / 2,186배관 / 독립 루프 23개. 충돌 높이는 계속 미확정.
- 관련 테스트 111개 통과, 별도 실행 조건의 테스트 5개 스킵.

이는 입력 변환·표시·파일 재파싱 검증이다. PIPENET의 실제 수리해석 완료나
실측 표고 확인을 의미하지 않는다.

검증 산출물: `outputs/module_f_single_elbow_rise_20260927/verification.json`.
서버 반영 후 도면을 다시 열고 물흐름 → 후보 선정 → 표 확정 → SDF 생성을
다시 실행해야 한다. 이전 표나 이미 내려받은 SDF는 자동 수정하지 않는다.
