# Module F — 루프·그리드 검토용 변환 / 작업 영역 자르기

## 사용 순서

1. 도면을 열고 필요하면 **02. 찍기 → 펜으로 작업 영역 → 영역 밖 제외**를 적용한다.
2. 배관 재료·헤드를 확인하고 배관망을 구성한다.
3. 손질에서 루프 또는 그리드를 선택하고 급수원 지정 → 물흐름 → 작동 헤드 후보 선정을 실행한다.
4. 수리계산에서 **검토용 기본 관경**을 직접 선택한다. 공통 기준 표고와 헤드 접속 치수도 확인한다.
5. 표 확정 후 SDF와 함께 생성되는 SLF, 검토 기록 JSON을 보관한다.

## 변환 계약

- 트리 경로는 기존 계산 경로를 유지한다. 루프·그리드는 별도의 검토용 변환기를 사용한다.
- 선정된 헤드에 이르는 모든 단순 급수 경로를 보존한다. 루프를 임의로 끊어 트리로 만들지 않는다.
- 관경은 명시적 수정 → 충돌 없는 도면 근거 → 사용자가 선택한 검토용 기본 관경 순이다. 루프·그리드에 규약 관경과 트리 담당 헤드 수를 적용하지 않는다.
- 화살표 방향은 입력 파일의 참조 방향이다. 실제 유량 분배나 역류 방향을 계산한 결과가 아니다.
- 실제 XY, 선언 길이, 계산 표고와 화면 표시 좌표를 구분한다. 매우 짧은 양의 길이가 3자리 반올림으로 0이 되지 않게 한다.
- SDF 파일명과 제목에 검토용·미확정/NOT VALIDATED를 표시한다. 통합 출력에도 이 표시를 전파한다.
- 검토 JSON에는 관경 근거, 기본값 사용, 부속 미해결 항목을 기록한다.

## 검토가 필요한 항목

- 본관·가지 표고는 사용자가 입력한 공통 기준이다. 호 기호의 가지 상승·우회 높이 및 알람밸브 수직 접속 형상은 이 변환기에서 자동 추정하지 않는다.
- 헤드는 명시된 상향·하향·상하향 접속 치수를 적용한다. 하향식의 국부 상승/하강이 180도 반환 형상이면 부속 검토 대상으로 남긴다.
- 분류티 손실은 기하학적 분기 포트 기준의 잠정값이다. 유량 해석 후 확인해야 한다. 크로스나 임의의 티 두 개를 만들어 보정하지 않는다.
- 기존 트리 위상 편집·특수 요소 편집을 조용히 이식하지 않는다. 지원하지 않는 기록이 있으면 정리 후 재확정을 요구한다.
- 공급 경계조건·노즐의 요구 유량·최소 압력을 PIPENET에서 확인해야 한다. 파일 열림은 수리계산 완료나 설계 적합 판정이 아니다.

## 자르기 계약

- 원본 DXF를 삭제하거나 변경하지 않는다. 작업 데이터의 바깥 요소를 제외해 이후 인식·추출·표시에 사용되는 양을 줄인다.
- 선분은 실제 다각형 경계에서 잘라낸다. 오목한 영역의 빈 곳을 직선으로 메우지 않는다.
- 경계에 걸쳐 잘리는 원/호 기호는 온전한 기호만 남기는 보수적 처리다. 문자는 삽입점으로 포함 여부를 판단한다.
- 원본 영역 복원 버튼을 제공한다. 자른 영역은 찍기 확정 시 저장되고 재추출 때 초기 단계부터 적용된다.
- 자르기는 02단계의 기능이므로 최초 DXF 읽기·펼치기 비용까지 없애지는 않는다.
- 자르기/복원 뒤에는 기존 손질·선정·계산표·통합 결과가 무효가 되어 다시 구성해야 한다.

## 검증 기록 — 2026-09-27

- B1F 컨셉2 수정본을 새로 읽어 저장 손질 상태와 대조했다. 저장 파일의 해시는 바뀌지 않았다.
- 전체 연결 헤드 285개를 호환성 시험 시나리오로 사용했다. 실제 최불리 설계면적 선정 결과가 아니다.
- 루프·그리드 각각 독립 고리 20개, 배관 1,965개, 노즐 285개, 총 배관 길이 1,145.114289377 m가 SDF 재읽기에서 보존되었다.
- 시험의 기본 호칭경 65 mm는 테스트 입력이며 실제 사용자 세션에 자동 적용하지 않았다.
- 부속 형상 미해결 항목 20개는 검토 JSON에 남았다.
- 별도 PIPENET 인스턴스에서 두 SDF를 열어 Pipe 1965 / Nozzle 285 / Node 2231 표시를 확인했다. Node 수에는 노즐 출구 절점이 포함된다.
- 루프 파일의 Check network는 `There must be at least two specifications`와 `Nozzle - optimum flow below minimum operating pressure`를 표시했다. 공급/노즐 조건을 임의로 만들어 계산을 통과시키지 않았다. 수리계산 성공은 미검증이다.
- 브라우저 자동 시험으로 실제 펜 입력 → 영역 밖 제외 → 원본 복원을 확인했다.
- 주요 회귀검사 178개 통과, 5개 선택 실행 검사 건너뜀, 기존 사용자 PNG를 덮어쓰는 검사 1개 제외. 산출물 특성 비교 22개 통과. 별도 순수 모델 검사에는 0길이 별칭·짧은 실배관·직접 속성 수정 검증을 추가했다.
