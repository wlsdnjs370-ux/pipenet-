# Module F SDF 노즐 표시 간격 (2026-09-20)

헤드 끝 절점과 노즐 삼각형이 겹쳐 보이던 이유는 SDF 대기 출구(`@/…`)의 표시 간격이 도면 범위의 0.25%에 불과했기 때문이다. 절점 좌표와 완전히 같지 않더라도 기호가 절점을 덮을 만큼 짧았다.

- 표시 간격을 도면 범위의 **2%**로 변경했다. 최소 간격은 표시 단위 1이다.
- 헤드의 실제 표고가 직전 배관 노드보다 높으면 위로, 낮으면 아래로 옮긴다. 아이소의 사선 방향이나 배관 input/output 순서로 방향을 추측하지 않는다.
- 실제 배관 끝 절점은 움직이지 않는다. 노즐 링크의 대기 출구 `Position x/y`만 바꿔 짧은 표시 연결선을 확보한다.
- 배관 추가 없음. 길이, 관경, 표고, 등가길이, 흐름, 상태, 연결 노드 번호, 라이브러리는 그대로다.
- 방향을 확정할 수 없는 수평/비말단 헤드, 공유 출구, 일반 이름의 실제 출구는 임의로 옮기지 않는다.
- 간격 계산에서 대기 출구를 제외하므로 반복 처리해도 계속 늘어나지 않는다.
- 적용 위치: `pipenet_converter/src/pipenet_converter/sdf_compat.py::prepare_sdf`. Module F 단독 및 통합망 SDF 출력의 공통 후처리 경로다.
- 이미 내려받은 SDF는 자동으로 바뀌지 않는다. 수정 서버에서 다시 생성·다운로드해야 한다. 확대율에 따른 실제 화면 픽셀 간격은 PIPENET이 결정한다.

검증: 상향/하향, 배관 역방향, 누락 대기 출구, 반복 처리, 공유/미확정 출구, 잘못된 간격 설정 및 대명동/B1F 저장 산출물의 전체 XML을 검사한다. 정상화 후 변경된 대기 출구 Position만 가리면 수정 전·후 XML이 동일해야 한다. PIPENET 실행 화면 자체는 이 자동 검사에 포함되지 않는다.
