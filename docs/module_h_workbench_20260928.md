# Module H — 단일 작업 화면 (2026-09-28 재구성)

## 범위와 불변 조건

- 기존 H의 4단계 화면·상시 사이드바·전용 청록색 테마를 교체했다.
- 진입 주소는 그대로 `/module-h`다. F의 색상, 글꼴, 각진 버튼을 상속한다.
- **F의 화면·계산 판단·저장/출력 형식은 보존한다.** 실제 진행 표시를 위한 공용 엔진의 읽기 전용 알림 추가는 별도로 승인받았다. F 스크립트에는 현재 작업 번호를 읽는 getter만 추가하며, 진행 UI는 H에서만 활성화한다.
- H 라우트는 F 문서를 읽어 H 전용 화면 구성만 덧붙인다. 원래 컨트롤의 ID·요소·이벤트와 기본값을 보존하고 필요한 위치로 이동한다.
- 계산 순서, 단위, 위상, 검증, 저장 및 출력 형식은 공용 엔진이 결정한다. H는 계산 함수를 복제하거나 사용자 입력을 자동 채우지 않는다.
- 저장 도면·편집 기록·업로드 저장소·라이브러리는 F와 공유한다. H 화면 교체로 사용자 데이터는 삭제하지 않는다. 같은 도면의 F/H 동시 편집은 피한다.

## 기본 화면

1. 머리: Module H, 현재 도면, 도면 업로드, 더보기.
2. 본문: 전체 폭 도면/아이소. 원래 캔버스와 좌표 기준 영역은 동일하다.
3. 하단: 현재 상태, 처리 내역, 다음 작업 버튼 하나.
4. 문제 발생 시: 미확정/오래된 표/오류의 간단한 안내. 클릭하면 기존 상세 근거를 연다.

상시 단계 탭은 없다. 「처리 내역」에는 기존 엔진의 단계 이동 컨트롤이 남아 있고, 기존 진입 조건을 그대로 따른다. 현재 위치나 입력표 생성은 설계 적합성·수리계산 검증 완료로 표시하지 않는다.

## 다음 작업 버튼

| 상황 | 제안 동작 |
| --- | --- |
| 파일 없음 | 도면 업로드 |
| DXF 파일 선택 | 별도 불러오기 확인 없이 업로드·읽기 시작 → 완료 후 객체 정의 또는 경로 추출 |
| 객체 정의 | 처리 영역·배관·헤드 분류 확인 → 배관망 준비 |
| 연결점 없음 | 알람밸브 지정 도구 열기 |
| 물흐름 미실행 | 방식 확인 → 기존 물흐름 |
| 헤드 미선정/손질 후 변경 | 기준개수·영역 확인 → 기존 후보 선정 |
| 선정 완료 | 입력값 검토 |
| 입력표 없음/옛 표/직접 입력 미반영 | 조건 확인 → 기존 표 확정 |
| 입력표 준비 | 기존 출력 단계로 이동 |
| 변환 | 형식 확인 → 기존 파일 생성 → SDF/SLF 다운로드 |
| 통합 | 도면 연결 조건 확인 → 기존 결합 → 원본 결합망 출력 |

한 번의 실행은 기존 버튼 하나만 호출한다. 단계 사이를 새 자동화로 연속 실행하지 않는다. 계산 조건이 있는 작업은 먼저 설정을 보여준다. 원래 비활성·작업 상태·취소 프로토콜은 유지하되 H 진행창은 우측 상단 비모달 창으로 옮긴다. 트리/루프/그리드 및 수동/자동/계통도 경로의 엔진 판단을 대체하지 않는다.

H의 파일 선택은 기존 업로드 핸들러를 한 번 실행한다. 별도 `불러오기`
버튼과 하단의 불러오기 확인 단계는 없다. 실제 읽기가 완료된 뒤에만 기존
엔진의 다음 작업으로 이동한다. 선택 취소는 아무 요청도 보내지 않으며,
처리 중 파일 선택은 비활성화한다. 실패·작업 중지 후에는 같은 파일도 다시
선택할 수 있고 자동 재시도는 하지 않는다. F의 명시적인 불러오기 버튼은
변경하지 않는다. 검증: `tests/test_module_h_upload_browser.py`.

현재 입력 양식과 엔진이 마지막으로 반환한 계산 설정(규격·신축배관·헤드 채움·루프 기본관경/기준표고)이 다르면, 다음 작업은 표 재확정으로 안내한다. 양식 변경만으로 새 계산이 완료된 것처럼 표시하지 않는다. 성공 후에도 현재 작업 창에서 원래 표 확정/통합 결합 버튼을 다시 실행할 수 있다.

## 더보기

- 도면 목록·추가: 평면도, 여러 계통도, 기계실 전환.
- 현재 작업·설정: 현재 단계의 기존 조작. 긴 정적 설명은 기본 화면에서 숨긴다.
- 보기 설정: 화면 전환, 원도면, 격자, 표시 좌표.
- 수리계산 입력표: 넓은 표, 핵심 열 우선, 한국어 열 제목, 숫자 정렬. 상세 열에서 전체 필드/원래 정밀도 확인. 기본 표시는 소수 셋째 자리까지만 반올림하며 원본/출력 값은 그대로다.
- 검토 항목: 기존 판정·위치 근거, 미확정 및 오류.
- 도면 통합·연결.
- 관경·펌프 역산: 원본 복사본에 대한 기존 검토안 계산/출력. 원본 결합망 출력과 구분.
- 출력 설정·다운로드: 기존 형식·기본 선택값 보존.
- 배관망 저장: 기존 손질 저장 동작.

변환 화면의 표는 읽기 전용이다. 표 행 선택과 아이소 속성 카드, 관경 편집, 되돌리기는 원래 동작을 사용한다. 창은 비모달이며 닫기/Esc와 포커스 복귀를 지원한다.

## 진행 표시·보조 창 (2026-09-28 추가)

- 표시 명칭만 `01 도면 업로드`, `02 객체 정의`, `03 배관 네트워크 정의`로 바꾼다. 내부 단계 키/처리 순서는 동일하다.
- 시작 화면은 설명 문장 없이 `DXF → SDF` SVG와 업로드 버튼만 표시한다. 사용자 요청으로 가운데 `f(x)`와 상자는 제거했다.
- 업로드/처리 시작 즉시 초기 화면을 숨긴다. 도면 수신 또는 다음 레이아웃 프레임까지 기다리지 않는다. 빈 상태에서 실패/취소한 경우 초기 화면으로 재시도할 수 있으며, 도면이 있으면 다시 표시하지 않는다.
- 작업/설정 창, 진행창, 개별/통합 배관 속성창, 직접 편집창, 편집 기록창, 수직 전개 입력창은 제목 표시줄로 드래그한다. 화면 경계를 제한하고 더블클릭으로 기본 위치에 복귀한다. 방향키는 10px, Shift+방향키는 40px 이동한다. 위치는 현재 페이지에서만 유지한다. 입력 확인용 모달의 확인/취소 규칙은 유지한다.
- 진행창에는 실제 작업명·경과 시간·수신 로그/상태를 표시한다. 전체 완료율을 추정하지 않는다. 엔진이 실제 퍼센트를 제공하는 구간만 수치를 표시한다.
- 처리 중 확대/이동, 조회용 표·내역·창 이동은 허용한다. 동일 작업의 입력 변경·망 편집·슬롯 변경은 작업 상태가 해제될 때까지 막는다. 별도 H 탭은 독립 세션이지만 저장 도면은 공유한다.
- DXF 해석 중 추가된 선/원/호, 레이어 표시 자료, 시작 노드부터 실제 탐색한 연결을 별도 캔버스에 표시한다. 탐색선은 유량 방향 또는 확정 배관 판정이 아니며 `미확정`으로 표시한다.
- 브라우저는 기존 작업 번호로 `/api/module-h/progress`를 조회한다. `ContextVar` 관찰자는 H 요청/해당 작업 스레드에만 연결하며 원래 세션·그래프·표를 수정하지 않는다. 결과 객체와 알림 유무에 따른 계산 결과 동일성을 테스트한다.
- 메모리 제한: 작업 채널 12개, 채널당 이벤트 192개, 응답 48개, 도형 이벤트 256개 단위, 클라이언트 도형 50,000개. 누락/상한 도달은 `간략 미리보기`로 표시한다. 최종 원본 화면·계산 데이터에는 이 제한을 적용하지 않는다.
- 원본 DXF 파일을 아직 해석하기 전에는 도형을 만들 수 없어 실제 로그만 표시한다. 캐시 사용/빠른 작업은 중간 화면 없이 완료될 수 있다. 보여주기 위한 인위적 지연이나 가짜 탐색 재생은 하지 않는다. 취소·완료 시 미리보기를 제거하고 늦게 도착한 이전 작업 자료는 무시한다.
- 길고 반복되는 안내는 기본 화면에서 제거하되 오류·옛 표·미확정 상태와 상세 근거 진입점은 남긴다.

## 한계와 배포

이 변경은 프론트엔드 재구성이다. 현장 설계 승인이나 PIPENET 내부 계산의 대조 완료를 뜻하지 않는다. 원래 엔진의 미확정/검토용 출력 제한 및 규칙을 유지한다.
