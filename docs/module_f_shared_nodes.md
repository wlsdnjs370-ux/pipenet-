# Module F 공통 절점 좌표 정합 (2026-09-20)

## 원인과 재현

- 평면도–계통도: 공용 schematic 배치는 노드 목록의 마지막 행을 AV로 간주하고
  정수 mm로 반올림했다. F의 실제 경로 배치도 그 결과를 기준점으로 받아,
  AV 행이 앞에 있는 추출 결과에서는 접속점이 2m 밀렸다.
- 계통도–기계실: `conn_xy`에 배관 노드로 스냅하기 전의 클릭 좌표가 저장됐다.
  실제로 병합해 없앤 접속 노드와 배치 원점이 달라 말단 배관이 늘어나거나 기울었다.
  `conn_xy`가 없는 이전 자료는 도면 범위의 중앙으로 정렬됐다.
- DXF 계통도는 실제 길이를 사용하지만 기계실은 평면도 크기에 맞춘 표시 배율을
  유지했다. 3m 배관이 1.414m로 그려지는 사례를 재현했다.

## 수정 범위

Module F의 어댑터에서 처리한다. A/E/G의 공용 추출·템플릿 코드는 변경하지 않는다.

- AV 라벨로 실제 공통 절점을 찾고 평면도의 정확한 XY에 상류 도면 전체를 정렬한다.
  평면도의 상대 표고는 기존과 같이 계통도 AV 표고로 기준을 옮긴다.
- 기계실은 `conn_node_label`이 가리키는 노드를 정렬 원점으로 사용한다.
  새 추출 결과에는 `conn_xy`를 실제 노드 좌표로 기록하고, 클릭은 `conn_pick_xy`에
  보존한다. 이전 결과도 결합 때 노드에서 다시 읽으므로 클릭 오차를 물려받지 않는다.
- DXF 계통도와 함께 결합하는 기계실은 배관 지정 길이와 각 노드의 상대 표고를
  사용한다. 공통 절점의 XYZ를 일치시키며 배관 추가·길이 재작성은 하지 않는다.
  새로 삽입한 펌프의 화면용 400mm 여백도 실제 배관 좌표에 넣지 않는다.
- 기계실 표고는 접속 절점 기준으로 통째로 옮긴다. 별도로 입력한 0이 아닌 수원 낙차가
  이 표고와 모순되면 오류를 알린다. 배관을 늘리거나 낙차를 조용히 덮어쓰지 않는다.
- 배관 길이보다 큰 표고차, 끊긴 경로, 모순된 루프는 기존 실제 좌표 검증기가 거절한다.
  밑그림은 원래 도면의 참조 형상이라 표고·지정 길이에 따른 개별 변형까지 따라가지 않는다.
  접속점은 같은 노드에 맞춘다.
- 미리보기에서 두 공통 절점을 모두 접속점으로 표시한다. 반복 결합 및 펌프 삽입으로
  원래 계통도 추출 데이터의 배관 끝점이 바뀌지 않도록 행을 복사한다.

## 검증과 적용

`tests/test_module_f_shared_nodes.py`는 노드 행 순서, 소수 mm, 스냅 오차,
이전 저장 형식, 잘못된 접속 라벨, 급수방식, 표고 기준, 펌프, 반복 결합,
평면/아이소 미리보기와 SDF/KFP의 연결·길이·배관 개수 보존을 검사한다.
이 회귀와 기존 통합·편집·출력·브라우저 검사를 합쳐 256건이 통과했다.

대명동의 실제 계통도·기계실 DXF 경로와 최소 평면도 표를 결합해 추가 계측했다.
클릭 스냅 오차 161.2mm, 결합 67절점/66배관에서 자연낙차·펌프 모드 모두
공통점 오차 0, 배관 지정 길이와 3D 좌표 거리의 최대 차이는 약 1.2e-14m였다.
사용자가 선택한 B1F 작업 세션 자체를 재생한 검증은 아니다.

업데이트 후 기존 결과는 다시 **통합/결합 → 출력**해야 한다. 재시작으로 열린 작업이
초기화되었다면 저장 도면을 이어 열고 계통도·기계실 경로를 다시 추출한다.
기존 다운로드 파일과 원본 도면은 자동으로 수정하지 않는다.
