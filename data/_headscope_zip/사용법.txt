헤드 범위 선택 (마우스 올가미) — 다른 프로그램용 복사본
========================================================

이 폴더는 K-Fire 본체에서 기능을 뺀 것이 아닙니다.
같은 마우스 선택 로직만 복사한 독립 묶음입니다.
K-Fire 프로그램은 그대로 두었습니다. 이 폴더를 본체 소스에 넣지 마세요.


1. 바로 확인
------------
필요한 것: Python 3.10+, PySide6

    pip install PySide6
    python demo.py

[헤드선택]을 누르고 마우스로 범위를 그리면, 원(헤드) 중
중심이 그 범위 안에 들어온 것만 주황으로 바뀝니다.
ESC = 모드 종료. 드래그 중 우클릭 = 이번 그리기만 취소.


2. 다른 프로그램에 붙이기
--------------------------
필요한 파일은 head_freeform.py 하나뿐입니다.

PySide6 QGraphicsView 라면 아래만 넣으면 됩니다.

    from head_freeform import HeadFreeformSelector

    self.lasso = HeadFreeformSelector(
        self,                                  # QGraphicsView
        get_heads=self._head_centers,          # [(id, 화면중심점), ...]
        on_selected=self._on_heads_picked,     # 고른 id 목록
        on_empty=lambda: print("범위에 헤드 없음"),
        on_mode_changed=self.btn.setChecked,   # 선택 끝나면 버튼 OFF
    )

    def mousePressEvent(self, e):
        if self.lasso.handle_press(e):
            return
        super().mousePressEvent(e)

    def mouseMoveEvent(self, e):
        if self.lasso.handle_move(e):
            return
        super().mouseMoveEvent(e)

    def mouseReleaseEvent(self, e):
        if self.lasso.handle_release(e):
            return
        super().mouseReleaseEvent(e)

    def mouseDoubleClickEvent(self, e):
        if self.lasso.handle_double_click(e):
            return
        super().mouseDoubleClickEvent(e)

    def keyPressEvent(self, e):
        if self.lasso.handle_key(e):
            return
        super().keyPressEvent(e)

get_heads() 예시:

    def _head_centers(self):
        # 고를 대상만 넘긴다. 헤드만 넘기면 헤드만 골라진다.
        out = []
        for name, item in self.node_item_map.items():
            if is_head(name):
                out.append((name, item.sceneBoundingRect().center()))
        return out

모드 켜기:  self.lasso.set_mode(True)
모드 끄기:  self.lasso.cancel_mode()   # ESC와 같음

PyQt6 / PyQt5 를 쓰면 head_freeform.py 맨 위 import 만
그쪽 Qt 바인딩으로 바꾸면 됩니다.
PyQt5 는 event.position() 대신 event.pos() 를 쓰는 곳이 있습니다.
그때는 HeadFreeformSelector._scene_pos 한 줄만 고치면 됩니다.


3. 이 로직이 하는 일 / 안 하는 일
----------------------------------
하는 일
    - 마우스 드래그로 자유형 경로를 그린다
    - 버튼을 놓으면 시작점과 끝점을 이어서 닫힌 다각형으로 본다
    - 각 대상의 「화면 중심점」이 다각형 안인지 본다 (OddEvenFill)
    - 안에 들어온 id 목록을 돌려준다
    - 3점 미만이면 무효 (클릭만 한 것)
    - 범위 안에 대상이 없으면 모드는 켜 둔다 (다시 그리라는 뜻)
    - 하나라도 고르면 모드를 끈다

안 하는 일
    - 고른 헤드의 속성을 바꾸지 않는다
    - 메뉴를 띄우지 않는다
    - 배관/밸브/노즐을 구분하지 않는다 (넘긴 점만 본다)
