# Module H — 미세하게 어긋난 피팅 접속 복원 (2026-09-29)

## 원본 대조

`MF20-001_ 주거타워 소화설비 평면도`의 신고 위치:

- 원호 중심: (160634.227508053, 3007451.480906981) mm
- 통과 주배관: x = 160598.8556158524 mm
- 차이: 35.3718922006 mm
- 기존 `thru_arms` 통과관 기준은 25 mm. 가지관은 기호 중심에서 시작하지만 주배관은 기준 밖이어서 직접 접속이 누락됨.
- 좌우 대칭 위치에서도 동일 증상. 먼 쪽의 복귀 경로로는 이미 같은 연결 성분이므로 **성분 수/헤드 도달 수만으로 이 누락을 판별할 수 없음**.

## 적용 범위

일반 스냅, 트리 경로 선택, 루프/그리드 보존, 헤드 인식 규칙은 확대하지 않는다.
선택한 배관 재료의 270° 원호에만 다음 증거를 함께 요구한다.

1. 원호 중심 5 mm 이내에 자유단 하나가 있고, 열린 방향 ±8°로 반지름 절반 이상 뻗음.
2. 직교하는 통과관이 원호 양쪽으로 반지름 이상 계속됨.
3. 통과관은 하나뿐이며, 원호 중심이 통과관에서 가지관 방향 쪽에 있음.
4. 추가 허용 오차는 `min(반지름 / 4, 50 mm)` 이하. 기존 25 mm 이하 처리는 변경하지 않음.

각도 없는 기호, 원/헤드/획, 큰 틈, 짧은 획, 역방향, 후보가 둘인 평행관은 새 규칙으로 잇지 않는다.
다른 배관망/층을 구분할 근거가 부족한 경우 이 규칙은 일반적인 근접 연결의 대체물이 아니다.

원본 좌표를 이동하지 않고 실제 통과관에 분할점과 짧은 접속 간선을 추가한다.
원호의 `cx/cy`를 유지하며 `connection_xy`, `connection_offset_mm`, `connection_evidence`에 복원 근거를 기록한다.
트리 변환의 격자 정리 후에는 `connection_node`로 원본 접속점의 식별정보를 전달한다. 삭제·제외된 접속점을 다른 가까운 점에 다시 붙이지 않는다.
루프/그리드 높이 판정도 원호의 장식 중심이 아닌 입증된 접속점에서 수행한다.
