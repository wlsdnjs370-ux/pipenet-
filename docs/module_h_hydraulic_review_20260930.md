# Module H · 속성 선택 및 역산 검토 (2026-09-30)

## 변경 범위

- 표의 비입력 셀에서 누른 채 드래그: 연속 행 선택. Shift+클릭: 선택 추가/해제.
- 도면의 배관·헤드·라이브러리 피팅 선택은 같은 선택 집합을 사용한다.
- 다중 선택의 공통 속성만 일괄 수정한다. 전체 검증 후 하나의 편집/되돌리기 이력으로 저장한다.
- 길이·좌표·삭제 등 위상 변경은 일괄 처리하지 않는다. 원본 소유 도면이 서로 다른
  평면도/계통도 대상을 섞은 일괄 수정은 명확한 오류로 거절하며 부분 저장하지 않는다.
- 기존 피팅의 종류/개수/등가길이를 수정한다. 미확정 기기나 밸브를 자동으로 엘보로 바꾸지 않는다.
- 계통도·기계실의 절대좌표 문자열만 숨긴다. 내부 좌표와 선택점은 그대로 유지한다.
- 통합 원본 도면 반투명 표시를 기존 밑그림 기능에 연결했다. 표시 좌표와 계산 좌표는 바뀌지 않는다.

## 역산 진단·표·출력

- 원본 속성표와 **역산 결과 · 읽기 전용** 표를 분리한다. 호칭경과 실제 내경을 별도 열로 표시한다.
- 미달 헤드는 빨간 원/십자, 유속 초과 배관은 빨간 선으로 표시한다. 미달 목록에서 위치를 선택할 수 있다.
- 입력 변경/기준망 fingerprint 변경 시 색상 진단과 출력 권한을 무효화한다.
- 조건 충족 시에만 필요 Q/H 및 수원 검토량을 제시하고 별도 SDF/SLF 출력을 허용한다.
  미수렴/조건 미달은 시험값이며 물량이나 펌프 사양으로 확정하지 않는다.
- **관경·펌프 함께 재검토**는 joint + enlarge 방식이다. 기존 관경 이상만 검토하며
  미지정 관경도 포함한다. 사용자가 별도로 잠근 배관 및 관경별 기기 손실이 없는 배관은 계속 잠근다.
- 현재 선택한 작동 시나리오의 필요 성능이다. 최불리 구역 자동 탐색, 실제 펌프 곡선,
  효율·NPSH·모터 정격 선정은 지원하지 않는다. 최소 비용/전역 최적해를 보장하지 않는다.

## 수원 기본값과 적용 범위

기본값은 `configs/hydraulic_review.json`의 20분이다. H에서 기준망을 불러올 때 사용한다.
공통 계산 모듈에는 시간을 강제로 넣지 않는다. 계산식은 Q[L/min] × t[min] / 1000 = V[m³].

근거: [NFTC 103 2.1.1, 2026-07-01 시행](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000281674&chrClsCd=010201).
수리계산 가압송수장치의 분당 송수량에 20을 곱하는 일반 기준이다.

[NFPC 604 제6조](https://law.go.kr/LSW/admRulLsInfoP.do?admRulId=42497&efYd=0)는 고층건축물에 별도 수원 기준을 두며
50층 이상 조건을 구분한다. 40/60분은 검토 입력 선택지이지, 시간을 고르는 것만으로 해당 기준 충족을 인증하지 않는다.
공동주택·주차장 등 용도, 적용 시점, 작동 헤드 선정, 옥상 추가수원, 겸용수원, 유효/사수량은 별도 확인해야 한다.
이 도구의 선택망 수량을 전체 건물의 최종 수조 용량으로 사용하면 안 된다.

## 실제 도면 대조

기준망 176노드·179배관·13작동 헤드의 별도 검토를 실행했다. 원본 fingerprint 불변을 확인했다.

- 기존 fixed_supply 8bar / 미지정 관경만 설정: 유동해는 수렴했지만 13헤드 최소조건 및
  배관 r17/r19/r20 유속 초과. 내경 누락이 아니라 도면 관경 잠금과 제약 미달이 출력 차단 원인이었다.
- joint / 기존 관경 이상 확대: 조건 충족. 공급 1494.4285 L/min, 토출 3.785858 bar,
  차압 양정 38.6746 m. 입력 흡입 전수두·토출 속도수두는 모두 0m인 검토 가정이다.
- r17: 40→100A, r19: 40→125A, r20: 25→80A. 전체 최대 유속 4.8335m/s.
- 헤드 최소 실제 유량 114.0727 L/min, 최소 실제 압력 1.993905bar.
  사용자 80L/min·1bar 외에 헤드 라이브러리 최소압도 검사한다.
- 20분 시나리오 수원: 29.8886m³. 이는 최종 법정 수조 용량이 아니다.
- 일반/아이소 SDF·SLF 및 JSON 생성 성공. 실제 PIPENET GUI 재계산은 이번 검증에 포함되지 않는다.

실제 입력/이전 결과/재검토 결과는 `data/hydraulic_review_20260930/`에 보관했다.
실제 도면 계산은 재시작 전 서버의 동일 solver로 실행했으며 수원 수치는 계산 유량 × 20분이다.
새 코드로도 같은 실제 모델을 오프라인 재계산해 Q/H 일치와 29.8886m³ 물량 필드를 검증했다.
새 물량 필드 및 H UI는 격리 서버의 실제 solver → 읽기 전용 표 → SDF/SLF 왕복 시험으로 별도 검증했다.

## 검증

- 속성 일괄 편집·편집 복구·역산·수원량·다중 선택·미달 표시·통합 화면·관경 근거·SDF 압축 관련 148개 검사 통과.
- 실제 도면 재계산에서도 원본 연결망과 원본 관경은 변경하지 않았다.
- 사용자의 저장 완료 및 재시작 승인 후 5051 서버 재시작 완료. HTTP 200 및 새 H 자산 로딩을 확인했다.
- 별도 Chrome 탭에서 새 수원 입력·공동 재검토·반투명 도면·미달 표시 구성요소의 초기화와 브라우저 오류 없음 확인.
