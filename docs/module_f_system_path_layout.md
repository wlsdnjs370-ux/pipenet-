# 모듈 F 계통도 경로와 밑그림 분리

2026-09-17

2026-09-20 공통 절점 정합과 기계실의 실제 길이 배치는
[공통 절점 보정 기록](module_f_shared_nodes.md)을 따른다.

## 확인한 원인

공용 `stitch_riser_and_heads`는 계통도 절점을 같은 X의 세로 막대로 재배치했다.
막대 길이는 실제 표고 대신 평면도 크기와 기계실 표시 여백으로 정했다.
표고가 같은 10m 수평 경로도 16m 세로 표시로 바뀌는 경우를 재현했다.
이렇게 방향을 잃은 SDF의 Position으로 KFP를 만들면 원래 방향을 복원할 수 없다.

별도로 계통도 추출은 층 정보가 없을 때 도면 Y차를 높이로 추정한다.
같은 층의 기계실 평면이 함께 그려진 도면에서는 이 추정이 맞지 않을 수 있다.

## 변경

- 밑그림의 수직 정렬, 흰 점선 테두리, 회색 겹침 경계를 유지한다.
  밑그림 변환은 배관망이나 계산값을 변경하지 않는다.
- F에서 실제 DXF로 추출한 계통도는 원래 선택 경로의 방향과 지정 길이,
  표고로 배치한다. 수평 길이는 `sqrt(length²-높이차²)`로 구한다.
  순수 수직관만 XY가 같은 자리에 놓이며 아이소 화면에서 수직으로 보인다.
- 평면도 알람밸브를 공통 접속점으로 삼고 기계실도 새 접속점에 붙인다.
  미리보기와 SDF 아이소는 같은 투영을 사용한다. KFP는 투영 전 좌표를 쓴다.
- `계통도 표고 기준`에 `같은 층 · 표고차 0으로 시작`을 추가했다.
  선택 시 자동 추정 표고를 0으로 시작하고 원래 그래프에서 측정한 길이를 쓴다.
  종전 추정값은 추출 결과에 보존한다. 실제 높이차가 있는 부분은 기존 통합
  노드 속성 편집으로 입력한다. 같은 층이라는 이유만으로 국소 높이차가
  없다는 것을 자동 판정하지는 않는다.
- 층간 도면은 기존 표고 추정을 유지한다. 도면의 수평 방향은 선택 경로를
  표현하며, 방위 정보 없이 실제 건물 방위를 추정한다는 의미는 아니다.
- 기존 템플릿 및 다른 모듈의 공용 배치 함수는 변경하지 않았다.
- 루프의 길이/방향이 모순되면 명시적인 오류를 낸다. 연결을 삭제하거나
  길이를 늘려 맞추지 않는다.

## 검증과 사용

밑그림 단독 13건, 관련 계산·추출·통합 166건, 추가 기계실 정렬 및 실제 브라우저
검사를 수행했다(중복 제외 181건 통과). 수평/수직 혼합, 급수방식 독립성, 같은 층 추출, KFP 길이·연결,
밑그림 무변경, 기계실 접속 및 UI 선택 전달을 포함한다.

기존 통합 파일에는 원래 경로 방향이 이미 지워져 있으므로 새 설정으로 계통도를
다시 추출한 다음 통합·출력해야 한다. B1F의 같은 층 경로는 `같은 층`을 선택하고,
실제 높이차가 있으면 노드에서 수정한다. 이전 다운로드 파일은 자동으로 바뀌지 않는다.

## 2026-09-21 평면 보기 — 계통도 세로관을 세로로 (오너 확정)

**증상.** 통합 결합망을 평면(아이소 끔)으로 보면 계통도가 수평으로 누워 보였다.
대명동 통합 산출(9/21 16:32)을 재 보니 계통도 배관 27개 = 세로관 26 + 가로관 1.
위 «변경»대로 순수 수직관은 XY 가 같은 자리에 놓이므로, 위에서 본 평면 좌표에서는
세로관 26개(길이 합 91.8 m)가 기준점 10·기준점 1 두 점으로 접히고, 화면의 빨간
가로선은 입상관이 아니라 맨 위 가로관 r3(15.6 m) 하나였다. 표고·길이·rise 는 정상,
아이소는 정상.

**고친 규칙(배관 하나하나).** 높이차가 있는 계통도 배관은 평면 보기에서 세로로
(길이 = 높이차, 1 m = 1 m), 높이차가 없는 배관은 종전처럼 도면 방향 그대로.
식: 계통도 노드 y += (표고 − 기준점 10 표고) × 1000 mm. 기계실은 위에서 본 모양
그대로 접속 노드(pump_junction)를 따라 평행이동. 평면도는 그대로.
B1F 같은 층(계통도 표고가 전부 기준점과 같다)과 template 배치는 좌표가 하나도
안 바뀐다.

**어디서.** `merge.bake_combined_plan` 한 곳 — 통합 평면 보기(`/merge/preview` iso=0),
평면 .sdf(`emit_merged(plan_nodes=)`), 밑그림 정렬(`underlays`), 편집 미리보기
(`network_edit.project`)가 모두 이 함수를 쓴다. `combined.nodes` 는 건드리지 않는다.
KFP 는 종전처럼 실제 좌표 SDF 로 먼저 만들고, 그 뒤 같은 표·같은 배율로 평면 .sdf
를 한 번 더 쓴다(Position 만 다르다). HAS 는 그 평면 .sdf 에서 나온다.

**확인(같은 입력, 고치기 전 A · 후 B).** 대명동 모양 계통도+기계실: 아이소 .sdf·
.kfp(평면·아이소)·.slf 바이트 동일, 평면 .sdf 는 `<Pipe>`·`<Node>` 속성 전부 동일하고
Position 만 다름. 같은 층·template: 산출 전부 바이트 동일(.has 는 수정 전에도 실행마다
배관 라벨 한 칸이 바뀌는 기존 비결정성이 있어 비교에서 뺐다). 시험:
`tests/test_module_f_system_layout.py` (+4, 밑그림 부착 시험은 화면 좌표 기준으로 고침).
