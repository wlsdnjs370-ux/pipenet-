# B1F 71번 — 중복 원호·중심 획의 접속 방향 오인식

## 원본 대조

- 도면: `B1F 현장조사 소화설비 평면도_컨셉2-수정본 (1)`.
- 대상 CAD 좌표(mm): `(758744.743, -153051.534)`. 화면 번호보다 원본 좌표를 기준으로 대조했다. 현재 캐시의 원본 노드는 `N1129`; 과거 캐시에서는 `N19624`였다.
- 반지름 180mm, 약 271.53° 사발형 호 위에 같은 중심·반지름의 약 91.53° 괄호 호 두 개가 중복되어 있다.
- 같은 중심을 지나는 137.143mm의 짧은 원본 획이 추출망에서 약 68.57mm의 막힌 팔 두 개로 남았다. 실제 긴 북쪽 배관과 별개이다.
- 이 중 남쪽의 짧은 팔까지 물리 배관 포트로 집계하여, 닫힌 방향 3개 / 열린 방향 1개라는 모순이 발생했다. 단순히 호 모양을 못 찾은 문제가 아니었다.
- 왼쪽 약 281mm 거리의 별도 괄호 기호와 실제 배관은 유지한다.

## 수정 범위와 안전 조건

`src/pipenet_converter/graph/arc_strokes.py`가 아래 조건을 모두 만족할 때만 중심 획을 판정 근거에서 제외한다.

1. 같은 중심·반지름에 사발형 호와 그 안에 포함되는 서로 반대쪽의 짧은 호 두 개가 중복됨.
2. 중심 획의 두 끝이 대칭이며 기호 반지름의 절반 안에 있고, 다른 배관으로 계속되지 않는 막힌 끝임.
3. 추론된 이음만이 아니라 원본 직선 경로로 획을 재확인할 수 있음.
4. 남은 실제 배관은 기호 밖으로 이어지는 주배관 양쪽과 열린 쪽 가지관 하나임.
5. 해당 짧은 팔에 선정 배관, 헤드·급수원·밸브, 사용자 이음·길이 지정 등 보호할 근거가 없음.

원본 선·노드·연결은 삭제하지 않는다. 루프·그리드의 부속/표고 판독에서만 증명된 짧은 획을 포트 근거에서 제외한다. 기존 트리 경로에는 새 필터를 적용하지 않는다. 모호한 사례와 실제 네 번째 배관은 종전처럼 검토 대상으로 남긴다.

확정된 결과는 주배관 분류티 → 설정된 상승 높이의 수직관 → 가지관 90° 엘보이다. 0.5m는 도면 축척에서 추정한 값이 아니라 기존 가지 상승 설정이며, 다른 설정값도 유지한다. 전체 루프의 표고 제약이 충돌하면 이 판정을 취소하고 미확정으로 남긴다.

제외한 포트, 원본 획 경로와 기호 좌표는 `arc_report.symbol_strokes`에 기록한다. 판정 미확정과 관경 미확정은 별개로 유지한다.

## 검증

- 회전 4방향 × 루프/그리드 × 상승 높이 0.5/0.8m: 동일한 티·수직관·엘보.
- 원본 증거 없음, 중복 기호 없음, 다른 중심, 비대칭 획, 실제 가지, 원본 추가 분기, 사용자 보호, 선정 헤드: 잘못 자동 확정하지 않음.
- 바로 옆 통과 갈래는 티+티로, 대상 관말 갈래는 티+엘보로 각각 독립 유지.
- 표고가 충돌하는 복귀 경로는 그대로 미확정 유지.
- 실제 저장 B1F의 13헤드 선택망에서 루프·그리드 양쪽의 표·아이소 검사 카드·SDF 내보내기/재파싱 확인. 헤드 13개와 독립 루프 4개 유지.
- 원본 모델 대비 노드 1개·배관 1개·실제 길이 0.5m 증가. 새 수직 접속 이외의 원본 길이와 트리 물흐름 경로 유지.
- 연속관 정리 후 검증망은 68노드/71배관. 해당 표 번호는 하단 71(티), 상단 72(엘보). 번호는 선택 범위에 따라 달라질 수 있다.
- 별도 하향식 헤드 접속부의 180° 미확정 4건은 이번 수정과 무관하며 그대로 남긴다. PIPENET 앱 내부 수리계산을 수행했다는 의미는 아니다.

실제 도면 검증 결과: `outputs/module_f_overlapping_arc_20260928/verification.json` 및 하위 검토용 SDF/KFP.

재현: `MODULE_F_FITTING_AUDIT=1`과 출력 디렉터리 `MODULE_F_FITTING_OUTPUT`을 설정하고 `tests/test_module_f_loop_fittings_repair.py::test_real_selected_b1f_roundtrip` 실행. 사용자 세션 대신 별도 시험 세션을 사용한다.

기존 브라우저 회귀시험 3건은 화면 정리 후 접힌 고급 설정/검토 기준을 먼저 열도록 시험 절차만 갱신했다. 프론트엔드 제품 코드와 계산 조건은 변경하지 않았다.

최종 관련 회귀시험: **217개 통과, 4개 조건부 건너뜀**. 실제 B1F 도면의 루프/그리드 출력 검증은 건너뛰지 않고 실행했다.
