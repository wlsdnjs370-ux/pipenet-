# Module F 루프·그리드 부속 수정 — 2026-09-27

## 원본 대조와 원인

현재 B1F 컨셉2-수정본 (1), 급수원 CAD (662681, -180629.4), 선택 헤드 13개를 재현했다.
기존 화면과 동일하게 208절점·213배관·독립 고리 6개가 나왔다.

1. 부속 판정은 실제 절점에서 했지만 결과에 절점 ID를 보존하지 않았다.
   표/카드는 손실을 싣는 배관의 입력점을 설치 위치로 사용했다. 루프의 출력 방향과
   배관 열거 순서는 설치 위치가 아니므로 직선상의 엘보, 옆 노드의 티가 나타났다.
2. 루프 변환은 호 기호와 가지 상승 치수를 읽지 않고 모든 본관/가지를 공통 표고로
   출력했다. 트리에서 정상 전개하던 상부 엘보/티가 평면 티로 남았다.
3. CAD (758463.6, -153051.5) 주변의 원본 재료는 직선 중심 연결이다.
   자동 이음은 20 mm 옆 접속점에서 위/아래로 대각선 이음을 중복 생성했다.
   원본 중심을 경유하는 연결이 이미 존재하므로 작은 삼각 고리 2개는 실제 루프가 아니다.
   모드 투영에서 원본 호 중심·원본 간선·우회 경로로 입증된 중복 자동 이음만 제외한다.
   원본 DXF, 저장된 손질, 트리 그래프에는 쓰지 않는다.

## 변경된 계약

- 부속마다 실제 설치 절점, 손실 귀속 배관, 검토 상태를 별개로 보존한다.
  양 끝에 부속이 있는 배관에서도 두 설치점을 잃지 않는다. 통합 시 절점 ID도 이동한다.
- 티는 가지 포트에 검토용 손실을 귀속한다. 루프의 참조 화살표를 실제 유향이라고 표시하지 않는다.
  직류티 제외 정책과 수리계산 미확정 표시는 유지한다.
- 호의 닫힌 포트/열린 포트를 나눠 세로 연결을 만든다. 방향은 원본 포트로 판단하며,
  실제 높이는 기존 입력 칸의 가지 상승값(기본 0.5 m)이다. 높이가 CAD에서 측정됐다는 뜻은 아니다.
- 수평 연결 성분마다 표고를 하나 정하고 모든 상승/복귀 연결의 높이 방정식을 동시에 검사한다.
  서로 충돌하면 해당 기호 묶음의 높이만 미확정으로 남기고 원본 연결·기준 표고를 유지한다.
  임의로 루프를 끊거나 길이를 늘리지 않는다. 검토용 출력은 유지하되 높이 확정을 주장하지 않는다.
- 호의 짝으로 입증되는 우회 구간도 처리한다. 짝 없는 호, 중복된 각도 기호는 미확정 목록에 남긴다.
- SDF와 함께 나오는 review JSON에 호 판정과 중복 접속 정리 근거를 포함한다.

## 실제 선택망 검증

- 수정 후 루프와 그리드 모두: 212절점 / 215배관 / 13노즐 / 실제 독립 고리 4개.
- 중복 접속으로 생긴 고리 2개 제거, 호 기반 입체 접속 7곳 반영.
- 배관 총길이 199.537850017 m (설정한 세로관을 포함).
- SDF 저장 후 재파싱: 연결, 고리 수, 노즐 수, 총길이, 표고차≤길이 검사 통과.
- 같은 원본의 트리 간선 집합과 손질 좌표·간선은 변경되지 않음.
- 전체 284개 헤드 KFP 검토 출력도 확인: 2,149절점 / 2,171배관 / 독립 고리 23개.
  확인 가능한 입체 접속 60곳, 높이 충돌 기호 1곳(N36177)은 원본 연결과 미확정 표고로 보존.
- 남은 검토 4곳: 새 표 기준 71(겹친 호·4방향 접속), 119·108·82(대응 우회 호 미확인).
  이 번호는 이 선택망 재현 기준이며 영역/헤드 변경 시 달라진다.

이는 입력 파일 형식/연결 검증이며 PIPENET 수리해석 완료나 설계 승인 검증이 아니다.
새 작업에서는 물흐름 → 후보 선정 → 표 확정 → 출력이 필요하다.

  이 실행에는 현재 선택망의 실제 DXF 캐시 대조, 루프/그리드 SDF 재파싱,

  `test_module_f_consistency.py`의 미사용 HTML ID 검사는 다른 JS 파일에서 참조하는
