# Module F 통합 아이소 표시 배율 — 2026-09-20

## 원인과 근거

사용자 첨부 평면 단독 SDF와 `module_f_merged_iso (5).sdf`를 비교했다.
두 파일의 Graphics 표시 설정은 같았지만, 평면 단독은 평면의 XY 폭을 3000으로
정규화한 뒤 투영하고, 통합은 높은 입상관까지 투영한 전체 폭을 다시 3000으로
축소했다. 첨부 파일의 평면 부분은 단독 대비 약 36% 크기였다.
노드 번호는 두 산출에서 달라졌으므로 번호 +9만으로 좌표를 대조하면 안 된다.
좌표군의 균등 축소 비교에서는 대부분의 평면 형상이 유지됨을 확인했다.

노즐 기호 간격 또한 전체망 폭의 2%여서, 긴 계통도를 더할수록 평면 배관에
비해 노즐 간격이 커졌다. 이는 수리계산 오류가 아니라 표시 기준의 차이다.

## 수정 범위

- `reference_display_scale`: 평면도의 원본 XY 범위로 단독 출력과 동일한 배율 산정.
- 통합 출력은 이 배율 하나를 평면·계통·기계실 모두에 동일하게 적용.
  X/Y 비율을 따로 늘리거나 부위를 따로 이동하지 않으므로 공통점은 유지된다.
- 노즐 간격도 평면도 절점 범위만 사용. 층고/입상관 길이에 영향을 받지 않는다.
- 기존 공용 출력 함수에는 선택 인자만 추가. 미지정 호출은 기존 동작을 유지.
- 입력 원본 및 길이·표고·관경·유량·부속·기기·연결은 불변.
  KFP는 계속 실제 3D 좌표로 생성하며, 아이소 KFP도 그 파일과 동일하다.

전체망을 한 화면에 맞춰 보면 입상관 때문에 평면 부분이 작게 보일 수는 있다.
이번 변경은 입상관 높이를 임의로 줄이거나 실제 좌표를 재배치하지 않는다.
대신 SDF 내부 평면 배율을 유지해 확대했을 때 기호가 지나치게 커지는 원인을 제거한다.

## 검증

- 동일 평면에 4m/80m 계통도를 각각 결합해, 단독 SDF와 평면 표시 벡터 및
  노즐 간격 일치 확인.
- 수정 전/후 SDF에서 Position을 제외한 Nodes/Links 전체 요소·속성이 동일함을 검사.
- 기존 좌표·공통점·편집·부속·4m 층고 환산·내보내기 포함 회귀 시험 수행.
  Module F 관련 193개 및 파서/작성기/펌프/길이 권위/설계 출력 53개 통과.
  외부 선택 샘플 SDF 부재로 기존 시험 1개만 건너뜀.
- 첨부 파일의 과거 상태로 표시만 바꾼 검토본은 약 2.764배로 확대된다.
  계산 항목 전체 불변 및 원본 표시 좌표 재현 오차 0.005 단위 미만 확인.
- `data/module_f_display_review_20260920/display_comparison.png`는 좌표 기반 비교 그림이지
  PipeNet 실제 화면 캡처가 아니다. 같은 폴더의 historical SDF는 과거 계산값을 유지한
  검토용이며, 4m 재산정 결과물로 사용하면 안 된다. 원본 다운로드는 수정하지 않았다.

서버 반영 후 저장 도면에서 통합을 다시 구성해 새로운 SDF를 생성해야 적용된다.
