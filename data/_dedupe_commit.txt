중복을 걷어낸다 — 찍기 「상태」 · 헤드 종류 그림 · 겹치는 MODULE A 표

■ 찍기의 「상태」 다섯 줄 제거

모드 / 재료 묶음 / 헤드 픽 / 헤드 칸 / 클릭 회수 — 전부 단추가 이미 말하고
있던 것이다:

    찍기가 켜졌나   → 「배관 선택」이 눌린 모양
    재료가 찼나     → 「선택 완료」·「배관망 구성」의 활성 여부
    헤드 칸이 뭔가  → 「상향/하향」·「상하향」의 눌린 모양
    무엇을 찍었나   → 캔버스와 아래 상태줄(say)

같은 사실을 두 곳에서 말하면 한쪽이 늦게 갱신되는 날 어느 쪽이 참인지
알 수 없게 된다. 단추 상태 동기화는 그대로 두고 표시만 걷어냈다.

■ 손질 「고른 헤드 종류」의 그림 제거

여기서는 「어느 종류로 바꿀까」만 고르면 된다 — 전개 모양은 변환 창에서 같은
그림으로 다시 본다(거기서는 칸 이름이 「① (m)」 뿐이라 그림이 곧 이름표다).
그림 세 장이 92px 씩 차지하던 자리가 사라져 최불리 선정이 한 화면에 들어온다.

■ 카드·표 중복

  · 「찍기 후보 제안」 카드를 「자동 추천」 카드 안으로 넣었다. 둘 다 모듈 A 의
    자동 추천이고 같은 단계에 뜨는데 카드가 나뉘어 MODULE A 표가 두 번 떴다.
  · 손질 패널에 MODULE A 표가 셋이었다(자동 이음 · Remote 30 · 영역 가두기).
    같은 출처이므로 묶음 제목 하나에만 남겼다.
  · 산출물 체크박스의 MODULE A / MODULE G 표, 수리계산 제목의 MODULE G 엔진 표를
    뺐다 — 어느 모듈이 만들었는지가 그 칸에서 할 일을 바꾸지 않는다.
  · 「이음 여유 — 도면에서 잰 값이 기본, 직접 고를 수도 있습니다」 → 「이음 여유」.
