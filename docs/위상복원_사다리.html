위상 복원 사다리

DXF 도면이 수리계산에 넣을 수 있는 배관망이 되기까지, 단계마다 무엇이 들어가고 어떤 규칙으로 무엇이 나오는지. 수식은 코드에 적힌 그대로이고 눈금은 전부 mm 입니다.

찍은 것 밖은 안 본다 사람이 재료로 고른 레이어×색 밖의 도형은 쓰지 않는다. 필요해 보이면 조용히 주워 오지 않고 «안 찍으셨습니다»로 알린다.
헤드는 관말이다 헤드 원을 티처럼 통과시켜 좌우를 잇지 않는다. 헤드에 팔이 둘로 보이면 도면을 잘못 읽은 것이지 갈림길이 아니다.
도면에 없는 고리를 만들지 않는다 이음을 얹을 때 두 끝이 이미 한 덩이면 버린다(union-find). 근거 없는 자리는 추측하지 않고 사람에게 묻는다.

선분 더미가 그래프가 되는 순서

위상이란 결국 노드 집합 V와 간선 집합 E입니다. 도면은 선분 더미이지 그래프가 아닙니다. 사다리는 «선분 → 그래프»를 한 번에 하지 않고, 근거가 강한 순서로 간선을 하나씩 더합니다 — 닿아 있으면(1) → 접속표시가 있으면(2) → 설명자가 있으면(4) → 헤드가 덮고 있으면(5). 각 단계는 앞 단계 그래프에 간선을 더하기만 하고, 마지막에 물길(6)로 «급수원에서 닿는 것»만 남깁니다.

모든 단계가 함께 쓰는 자 — 공용 수식

단계마다 눈금은 다르지만 재는 방법은 넷뿐입니다. 아래가 그 넷이고, 뒤의 모든 규칙은 이 넷의 조합입니다.

점 p 에서 선분 ab 까지 — seg_geom / seg_dist
  t  = ((p − a)·(b − a)) / |b − a|²         투영 위치
  t̂  = clamp(t, 0, 1)                        선분 «안»으로 자름
  f  = a + t̂·(b − a)                         발점
  d  = |p − f|                               거리

두 방향 사이 각 — ang_between
  θ  = acos( (u·v) / (|u||v|) )              도(°) 로 비교

축 u 에서 벗어난 정도 — 횡이탈(lateral)
  n  = (−u_y, u_x)                           u 의 법선
  lat = |(q − a)·n|

격자 — 후보만 줄인다. 판정은 반드시 위 거리식이 한다
  cell(p) = (⌊p_x / c⌋, ⌊p_y / c⌋)           c = 30 · 100 · 400 · 500 · 1000 …

네 가지 자가 전부입니다. ① 는 t 를 0~1 로 자르기 때문에 «선분 밖의 점»도 항상 끝점까지의 거리로 답합니다 — 무한 직선이 아니라 선분이라는 뜻입니다. ④ 는 판정이 아니라 후보 추리기입니다. 격자 칸 크기(30·100·400·500·1000)는 단계마다 다르지만, 칸에 걸렸다고 이어지는 것이 아니라 그다음 거리식을 통과해야 이어집니다.

헤드 틈 접착 — 다른 색 토막이 «헤드 틈»으로 재료 끝에 붙어 있으면 재료로 승격

1-b A1 겹침 합치기 — 두 번 그린 선을 하나로

같은 묶음의 두 선분 i, j (단위방향 u_i, u_j · 긴 쪽을 기준축으로)
  평행     |u_i × u_j| = |u_ix·u_jy − u_iy·u_jx| ≤ sin 1°
  횡이탈   lat = max( |(a_j−a_i)·n|, |(b_j−a_i)·n| ) ≤ 50   탐색 띠
  포개     s₁ = (a_j−a_i)·u_i,  s₂ = (b_j−a_i)·u_i
           ovl = min(max(s₁,s₂), L_i) − max(min(s₁,s₂), 0) ≥ 1
  → union-find 로 사슬을 묶고, 사슬마다 축 위 구간의 합집합 하나로 바꾼다

둘을 안 합치면 SNAP 30 이 두 벌의 노드를 만들고, 그 위에 서는 팔·닿음 판정이 전부 흔들립니다. 그래서 조립 «전» 전처리로 둡니다. union-find 로 사슬을 묶는 이유는 셋 넷이 연달아 겹쳐 그려진 경우에도 한 번에 하나로 접기 위해서입니다.

이 단계가 위상 복원의 심장입니다. 도면에서 배관은 접속부 기호(반원·원·짧은 획) 앞에서 끊겨 그려집니다. 그 기호가 «여기서 이어진다»는 허가이고, 기호에 모인 관 끝을 팔이라 부릅니다. 팔이 둘 이상이면 잇습니다 — 반경이나 방향을 따로 증명하지 않습니다.

2-a 접속표시 — 무엇을 표시로 보나

표시 s = (kind, c, r)
  «호»   재료 레이어의 ARC,     0 < r ≤ 300
  «원»   재료 레이어의 CIRCLE,  0 < r ≤ 300,  헤드 원은 제외
  «획»   본체가 «모양으로» 재료에서 뺀 짧은 선 (작대기·관말 캡)  — c = 중점, r = L/2
  «헤드» 반지름 자를 통과한 닫힌 원 — 잇지 않는다. 물닿음 잣대에만 쓴다

레이어 이름이 아니라 도형 종류로 가릅니다. 3F 도면은 헤드와 접속부가 레이어(SP)·색(3)·반지름(150)까지 똑같고 «원이냐 호냐»만 달랐습니다 — 레이어로 가르던 옛 방식은 접속부 반호 353개에 「헤드」 이름표를 달았고, 그것이 3F 오이음 150곳의 원인이었습니다.

2-b 팔 — 표시에 «앉은» 노드

노드 n 은 표시 s 의 팔  ⇔   |n − c| ≤ 5          중심에 앉음 (ARM_CTR)
                         or  | |n − c| − r | ≤ 12   테두리에 앉음 (ARM_RIM)
                         헤드 표시는 테두리 여유 50   HEAD_RIM — «육안으로 붙은 것»

여유가 12 인 이유와 헤드만 50 인 이유가 다릅니다. 12 는 «그리기 오차»고, 50 은 «사람이 붙었다고 보는 거리»입니다. 그리고 헤드에 팔이 둘 이상 붙으면 그 헤드는 배관 위에 걸쳐 그려진 것이라, 헤드 때문에 끊긴 관이 여기서 이어집니다.

2-c 통과 팔 — 표시 «안을 지나가는» 관도 팔이다

메인이 끝점 없이 곧게 지나가면 팔이 0개라 가지관과 영원히 안 만납니다 — 도면에는 십자로 그려져 있는데도. 그래서 중심을 지나는 관을 그 자리에서 쪼개 새 노드를 팔로 넣습니다. 스치는 관과 헷갈리지 않게 문을 두 겹으로 잠급니다.

비헤드 표시 s 와 간선 (i, j), L = |p_j − p_i|
  t ∈ [0, 1]                    선분이 중심 옆을 지남
  d(c, ij) ≤ 25                 THRU_OFF — 정중앙을 지나야
  60 ≤ t·L ≤ L − 60             THRU_IN — 끝에 앉은 것은 이미 팔
  → 발점 f 에서 쪼갬: V ← V ∪ {f},  (i,j) → (i,f),(f,j),  f 를 s 의 팔에 추가

  L < 120 이면 쪼갤 «안쪽»이 없다 → 중심에 더 가까운 끝을 팔로
  «획» 표시 + 평행(≤15°) + 중심에서 5 밖 → 스침. 팔 아님   규칙 A

«지나간다»와 «스친다»를 가르는 문이 둘입니다. d ≤ 25 는 정중앙을 지날 것, 안쪽 60 은 끝에 앉은 것과 구별할 것. 규칙 A 는 세 번째 문인데, 획 표시에만 걸립니다 — 획은 «작대기»라 그 옆을 나란히 지나는 관이 많기 때문입니다.

2-d 잇는 순서 — 가로 먼저, 허브, 나머지

예전에는 첫 팔에 나머지를 전부 붙이는 별 모양이었고, 첫 팔이 짧은 선 끝이면 좌우 메인이 그 점으로 45° 끌려 올라갔습니다. 지금은 셋으로 나눕니다.

팔 ≥ 2 인 비헤드 표시 s (팔 집합 A, 중심 c) 마다
  chord(u, v):  중심이 선분 uv «사이»에 있는가
      t = ((c − p_u)·(p_v − p_u)) / L²,   e = min(0.45, 5 / L)

  ① 통과 가로   남은 팔 중 chord 값이 최소인 쌍을 뽑아 잇는다. 반복.   티 = 1쌍 · 십자 = 2쌍
  ② 허브        hub = argmin_{n∈A} |n − c|                              보통 2-c 가 만든 중심 노드
                 hub 가 ①에 없으면 ①의 노드 중 가장 가까운 것에 잇는다
  ③ 나머지 팔   ①②에 안 든 팔 → hub 에 잇는다                            헤드로 가는 짧은 선 등

3단계 · 검사

헤드 접속 — 비어 있다

이 단은 이음 목록이 항상 빈 목록입니다(j3 = []). 대신 안전핀이 하나 걸려 있습니다 — 2단계 이음 중 «헤드» 표시를 통과한 것이 하나라도 있으면 성적표의 head_joins 가 0 이 아니게 되고, 그것은 «배관이 헤드를 경유해 이어졌다»는 뜻이라 수리계산 대형사고로 봅니다. 실제 헤드 접속은 6단계의 물닿음 잣대가 «관 끝이 헤드에 앉았는가»로 판정합니다.

5단계 · +E, +V

상향식 헤드 접속 — 원이 덮은 자리

들어감g + 헤드 원(c, r) + 1-1 라벨
→
나옴헤드 자리 틈이 이어진 g · 원 밑 통과관의 중심 노드

상향식 헤드는 배관 위에 티로 올라앉습니다. 도면에서는 관이 헤드 원을 관통하다가 원 자리만 비워져 있습니다. 그 모양만 잇습니다 — 헤드를 통과점으로 쓰지 않고 메인끼리 잇습니다. 후보는 상향식·미지정·상하향식(비팔)뿐이고 하향식에는 이 문을 열지 않습니다.

① 헤드 덮음 틈 이음 — join_by_head_cover · 자유단 쌍 (p_a, p_b), L, u = (p_b − p_a)/L
  along = (c − p_a)·u          lat = |(c − p_a) × u|
  원이 축을 자른다     lat < r
  half = √(r² − lat²)                                  축 위에서 원이 차지하는 반길이
  원 밖으로 남는 길이   along − half ≤ 150   and   L − (along + half) ≤ 150
  → 이음 후보 (a, b).  add_no_ring 으로 얹는다

② 원 밑 통과관 중심 분할 — stage5_split_through_uprights
  헤드에 중심(≤5)·테두리(±50) 노드가 없고, 간선이 원 안(d(c, ij) ≤ r)을 지나면
  → 중심 c 에서 쪼갬: V ← V ∪ {c}

눈금을 원 크기 비례(틈 ≤ 4r · 남는 길이 ≤ 2r)로 바꿨다가 되돌린 자리입니다. 비례는 남는 길이를 360mm 까지 봐줘서 아래 모양을 통과시켰습니다. 120 → 150 으로 올린 것은 판정에 쓰는 남는 길이가 반지름이 아니라 현(弦) 기준이라, 헤드가 축에서 비껴 있을수록 커지기 때문입니다(MF3 실측 125·134 / 92·119).

150 은 «그리기 여유»입니다. 원 크기에 비례시켰다가(틈 ≤ 4r · 남는 길이 ≤ 2r) 되돌렸습니다 — 비례 눈금은 헤드가 틈 한쪽 끝에 붙어 있고 반대쪽 257mm 가 빈 모양까지 통과시켜, 서로 다른 두 헤드의 접속관을 617mm 건너 붙였습니다(MF3). 120 → 150 으로 올린 것은 현(弦) 기준이라 헤드가 축에서 비껴 있을수록 남는 길이가 커지기 때문입니다.

설계 · 부분 그래프

최불리 corridor — 수리계산에 넣는 위상은 이것이다

들어감평면 그래프 + 급수원 + 기준개수 K
→
나옴corridor 부분 그래프 · 간선마다 담당 헤드 수 · 앵커 · 최원 유하거리

NFPC 103 의 기준개수 K 는 «하나의 설계구역 안에서 동시에 방수되는 인접 K개»입니다. 급수원에서 먼 순서로 K개를 뽑으면 도면 곳곳의 막다른 헤드가 섞입니다(B1F: 대각 95.9m 로 흩어짐). 그래서 앵커를 먼저 잡고 그 주변으로 뭉칩니다(30.3m).

후보 좁히기 — attachable_heads
  cand = 전개가 실제로 붙일 수 있는 헤드          빠진 수 dropped 는 반드시 화면에 — 배관이 끊겨 있다는 뜻

① 앵커 — 배관 거리로 가장 먼 헤드
  dist_S = Dijkstra(S, w(u,v) = |p_u − p_v|)
  anchor = argmax_{h ∈ cand} dist_S(h)          far_m = dist_S(anchor)    최원 유하거리

② 설계면적 — 앵커에서 «배관 거리로» 가까운 K개 (유클리드 아님)
  dist_A = Dijkstra(anchor)
  K = 가장 작은 dist_A 를 가진 헤드 K개  (anchor 포함)

③ corridor 와 부하
  corridor = ∪_{h ∈ K} path_S(h)                급수원→헤드 최단경로의 합집합
  load(e)  = | { h ∈ K : e ∈ path_S(h) } |      별표1 이 최소 호칭경을 정하는 그 값
  max_load → 주배관 관경

제한 전개 — corridor 를 표로

corridor 밖을 버리고, 평면에 없는 세로 구간을 규칙으로 얹습니다 — 헤드 접속관·가지 상승관은 도면에 그려진 선이 아니라 전개가 만든 선이라 역참조(edge_ref)가 없습니다. 그래서 관경 직접 입력이 그 배관을 가리킬 수 없고(BLOCKED §19), 관경은 담당 헤드 수로만 정해집니다. 도면에서 온 배관은 edge_ref 로 board 간선을 되짚어 관경 텍스트와 맞춥니다.

이 뒤는 위상이 아니라 값입니다 — 관경(max(도면 텍스트, 별표1 최소)), 부속, 5개 표, 그리고 .sdf / .kfp / .has 로의 치환.

다시 한 줄로

위상 복원은 다섯 규칙의 합이다

선분을 그래프로 접는 규칙(SNAP·닿음) + 표시가 허가한 자리에서만 잇는 규칙(팔·통과·순서) + 설명이 있는 틈만 잇는 규칙 + 물이 닿는 것만 남기는 규칙 + 최불리 K 를 급수원까지 잇는 최단경로의 합집합.
