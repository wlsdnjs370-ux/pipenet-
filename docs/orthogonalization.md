# 직교화(O2)와 루프 금지 게이트(O1)

추출된 배관망을 **모든 간선이 축평행(교차각 90°)인 트리**로 정규화한다.
`remote30_prototype.orthogonalize_edges` + `_finalize_selection` 의 union-find 게이트.

## 왜 필요한가

실제 스프링클러 배관은 건물 그리드를 따라 직각으로 돈다. 그런데 추출 결과에는
대각선이 섞인다. 대명동 201동 서측 세대 실측(`scripts/_ortho_probe.py`):

| 단계 | 비직각 간선 |
|---|---|
| 원시 그래프(`_build_graph`) | 287 / 856 (33.5%) |
| collinear merge 직후 | 51 / 79 (64.6%) |
| 직교화 후 | 0 / 116 (0.0%) |

원시 단계의 33.5% 는 **작도 오차**가 대부분이다(축과의 이탈각 ≤1° 가 32건).
병합 후 64.6% 로 뛰는 것이 본질 — `_finalize_selection` 의 collinear merge 가
`ELBOW_MERGE_TOL_DEG = 95°` / `SHORT_SEG_MM = 500mm` 조건으로 **직각 코너를 흡수**해
대각선 한 줄로 바꾼다. 길이는 실제 경로 합이라 맞지만 형상이 무너진다.

## 두 단계

### ① 축 스냅

짧은 성분이 `ORTHO_SNAP_EPS_MM`(25mm) 이하인 간선은 작도 오차로 보고 양 끝 좌표를
같은 축선으로 모은다. 좌표값 단위 union-find 라 한 축선에 걸친 노드가 통째로 정렬된다.

- **앵커(소스·헤드)는 절대 이동하지 않는다.** 앵커를 포함한 클래스는 앵커 값이
  목표가 되고, 앵커가 둘 이상이면 스냅을 포기한다(→②).
- 이동 폭이 `4·eps` 를 넘는 연쇄 클래스는 드리프트로 보고 포기한다(→②).
- 서로 다른 노드가 한 점으로 겹치면 위상이 바뀐다. **겹친 노드만** 제자리로
  되돌리고 다시 확인한다. 전면 취소하면 mm 급 어긋남까지 ②로 넘어가 **0mm
  세그먼트**가 생긴다(실측: 전면 취소 시 0mm 19개, 부분 되돌림 시 0개).

### ② L자 분해

남은 대각 간선에 코너 노드를 하나 넣어 축평행 2개로 쪼갠다.

- **길이는 원 길이를 `|dx|:|dy|` 성분비로 배분** → 간선 길이 합이 정확히 보존된다.
  관경 산정·마찰손실 결과 불변.
- **새 부속을 만들지 않는다.** 직교화는 형상 표현의 변경이지 배관 변경이 아니다.
  병합이 흡수해 둔 elbow(`elbow_fittings`)는 등가길이 부속이라 어느 세그먼트에
  달아도 수리적으로 동일하므로 살아남은 세그먼트로 옮긴다.
- 긴 성분을 먼저 진행하는 코너를 우선 택한다 — 주배관 방향을 유지한 뒤 끝에서
  꺾는 실제 배선에 가깝다. 그 자리가 이미 점유돼 있으면 반대쪽 코너를 쓴다.
- 노드 1개 + 간선 1개를 함께 늘리므로 **사이클을 만들 수 없다.**

## 루프 금지 게이트(O1)

최단경로 합집합은 경로가 갈렸다 다시 만나면 루프가 된다. 수리계산 입력은 가지식
이어야 하므로 서브그래프 구성 시점에 union-find 로 사이클을 닫는 간선을 버린다.
버리는 시점에 양 끝이 이미 연결돼 있으므로 **어떤 헤드도 끊기지 않는다.**

`load_mode` 의 `on_residual_cycle` 기본값도 `force_tree` 다. 격자 보존 요구는
철회됐다 — BLOCKED.md §11 · §13.

## 불변식 (tests/test_orthogonalization.py)

- 모든 간선이 축평행
- 독립 사이클 수 `E − V + C` = 0
- 총 연장 보존 (대명동 실측 오차 0.000000%)
- `source_pos` · 헤드 좌표 · `distances` 완전 동일
- 0 길이 세그먼트 없음
- 추정-edge(브릿지·용접·head-drop) 좌표가 스냅을 따라간다 — 프론트가 최종망 위에
  점선으로 겹쳐 그리므로 어긋나면 표시가 깨진다

## 끄는 법

`select_worst30_heads_anchored(..., ortho=False)`. 감사 기록은
`ExtractionAudit.ortho` (`snapped_nodes` / `max_shift_mm` / `snap_reverted_nodes` /
`snap_skipped_classes` / `split_edges` / `unresolved_diagonals` /
`edges_before` / `edges_after` / `cycle_edges_dropped`).

## 알려진 부작용

25mm 이하 짧은 세그먼트가 11개 → 13개로 늘고 최소 길이가 3.65mm → 1.70mm 가 된다.
스냅이 포기한 소수 간선의 L자 짧은 다리다. 직교화 전에도 mm 급 간선이 있었고
수리적 영향은 무시 가능하다.
