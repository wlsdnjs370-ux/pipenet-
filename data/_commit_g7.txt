[G7] 4번째 창 「수리계산 입력」 — 수용기준: PASS

찍기 → 손질 → 변환 **다음**에 오는 네 번째 창. 판정은 하나도 창에 없다 —
`services/cad_import/design/` 이 다 하고 창은 입력을 받아 결과를 보여줄 뿐이다
(모듈 E 의 다른 창과 같은 계약).

■ .kfp 저장 «뒤» 에 연다
  순서가 중요하다. 수리계산 입력 창이 떠 있어도 .kfp 저장은 이미 끝나 있어야
  서로 영향을 주지 않는다(§G7 수용 기준). 창이 실패해도 앞 단계를 무르지 않는다.

■ 막힘은 변환 창과 같은 방식으로
  급수 시작 위치 미지정·헤드 종류 미지정을 **사유와 함께** 화면에 돌려준다.
  조용히 실패하지 않는다. 막힌 동안 저장 단추는 열리지 않는다.

■ ★제외 헤드를 숨기지 않는다 (BLOCKED B4)
  최불리는 «배관에 붙는 헤드» 중에서만 고른다. B1F 실측으로 **2,544개가 빠진다**
  (후보 619 / 도면 3,163). 그 수를 창에 띄우고, 절반을 넘게 빠지면 «배관이 끊겨
  있을 수 있으니 손질 창에서 이어 주세요» 까지 말한다. 조용히 빼면 더 불리한
  헤드가 있는데 못 본 채 수리계산이 나간다.

■ 무거운 계산은 UI 스레드 밖
  `_CadEditBuildThread` 와 같은 패턴(`_DesignThread`) — 예외를 삼키지 않고
  들고 나와 창이 사유를 보여준다.

■ 검사가 헛돌던 것도 잡았다
  처음엔 창을 `show()` 하지 않고 `isVisible()` 을 쟀다. 부모가 숨어 있으면
  자식은 show() 해도 False 라, 메시지가 **정확한데도** 「안 보인다」로 읽혔다
  (2건 오탐). offscreen 으로 실제로 띄워 재도록 고쳤다 — 사람 화면엔 안 뜬다.

■ 수용 기준 (tests/test_design_dialog.py · offscreen Qt)
  · 급수원 없으면 막고 사유 표시 · 막힌 동안 저장 잠김
  · 요약에 설계면적·앵커·corridor 총연장·관경 근거·부속 전부 표시
  · 제외 헤드 2,544개 화면 표시 + 배관 이으라는 안내
  · 창을 다시 열어도 직전 K 유지(30 → 20)
  · 창 결과로 SDF 25,501 B + SLF 8,412 B 저장
