# Module F 회사 규칙 연결 및 자유곡선 영역

## 사용법

1. 찍기에서 필요한 배관/헤드 레이어를 선택한다.
2. ‘헤드 감지 규칙’ → ‘회사 표준 (PPT 26~36쪽)’을 선택하고 배관망을 구성한다.
   기본값은 기존 도면 규칙이며, 선택한 프로필은 찍기 설정에 보존된다.
3. 손질의 ‘회사 헤드 감지 결과’에서 확정/검토 결과를 확인한다.
4. ‘② 영역 지정’의 영역 모양을 ‘자유곡선 (펜)’으로 바꾼다.
   마우스를 누른 채 둘레를 그리고 놓으면 시작점과 끝점이 연결된다.
5. Esc는 진행 중 그리기를 취소한다. 영역 지정 중 Ctrl+Z는 마지막 영역을 취소한다.
   Shift+드래그는 화면 이동이다. 기존 사각형과 자유곡선을 함께 사용할 수 있다.
6. 손질 저장 후 다시 열면 영역의 실제 경계가 복원된다.

자동 추출의 영역 지정에도 같은 자유곡선 도구를 제공한다. 회사 헤드 규칙은
찍기를 사용하는 수동/하이브리드 구성에만 연결되며 순수 자동 추출에는 적용하지 않는다.

## 경계와 후보 판정

- 기존 사각형 데이터 `[x0, y0, x1, y1]`는 그대로 지원한다.
- 자유곡선은 `{"type": "polygon", "points": [[x, y], ...]}`로 저장한다.
- 좌표 단위는 기존 CAD 좌표의 mm이다. 화면 확대/이동으로 경계가 변하지 않는다.
- 실제 다각형 내부 및 경계 위의 헤드만 후보로 삼는다. 오목한 부분을 포함하여
  경계를 사각형으로 대체하지 않는다. 여러 영역은 합집합이다.
- 화면의 후보 수와 서버의 최불리 후보 제한은 같은 포함 판정 규칙을 사용한다.
- 주변 배관을 수집하는 별도 작업 범위는 넓게 잡을 수 있지만, 헤드 후보 제한은
  원래 영역으로 유지한다. 영역 변경 시 이전 최불리 결과는 무효화한다.
- 화면 입력은 약 1.2픽셀 허용오차로 단순화한다. 64픽셀² 미만 영역,
  영역당 512개 초과 꼭짓점, 64개 초과 영역은 오류 안내 후 거부한다.
- 자기 교차는 홀짝 포함 판정을 사용하나 면적이 0인 경계는 거부한다.
  의도한 둘레가 겹치지 않게 그리는 것을 권장한다.

## 구현 위치

- `src/pipenet_converter/graph/regions.py`: 입력 검증, 포함 판정, 영역 서명, 기존 HeadRegion 호환.
- `static/module_f_regions.js`: 화면의 포함/면적/단순화 계산.
- `static/module_f.js`, `templates/module_f.html`: 영역 입력과 회사 프로필/검토 UI.
- `routes/module_f/api_edit.py`, `api_auto.py`, `selection.py`, `auto.py`, `remote30.py`:
  영역 저장과 후보 제한, 계산/화면 전달.
- `cad_project_editor_g/services/cad_import/edit/io.py`: 손질 파일의 영역 보존.
- 회사 분류기와 DXF 어댑터의 범위/제약은
  [회사 헤드 규칙 문서](company_head_symbols_260404.md)를 참고한다.

## 검증

단위 시험은 오목 영역, 대각 경계, 경계 위 후보, 큰 CAD 좌표, 잘못된 입력,
영역 서명, Python/JavaScript 판정 일치, 회사 6종 기호의 회전/실제 DXF 채움,
불확실 근거, 프로필 적용 전후를 확인한다.

격리된 브라우저 시험은 자유곡선 그리기, 실제 내부 후보 수, 취소/되돌리기,
확대 후 좌표 보존, 사각형 병용, 손질 저장 요청을 확인한다.
API 통합 시험은 최불리 후보 제한, 저장 후 복원, 영역 비우기,
잘못된 저장 입력이 기존 손질 파일을 덮어쓰지 않는지 확인한다.
실물 MF-106 전체 도면의 헤드 검출 정확도는 이 시험에 포함하지 않는다.
