## 구현 범위와 안전 경계

- `src/pipenet_converter/graph/junctions.py`: 서버 독립 정규화. 이미 길이 0
  간선으로 연결된 점만 대표 ID로 통합한다(허용 오차 0.000001mm).
- 한 끝을 공유하고 정확히 같은 선 위에 놓인 관통/스텁 겹침만 분할한다.
  원본 X/Y를 이동하지 않는다. 인접하지만 연결되지 않은 점이나 X 교차는 잇지 않는다.
- 호 기호의 자동 이음은 그 기호의 팔들 사이에서만 연결 성분을 확인한다.
  이미 이어진 팔에는 또 이음을 만들지 않고, 후보 중 짧은 연결을 우선한다.
  기호 밖의 실제 순환망은 이 규칙으로 제거하지 않는다. 헤드 경유 이음 금지도 유지한다.
- `pipeline/flow.py`에서 물흐름 선택 전에 정규화한다. 트리가 이미 잘못된
  중복 경로를 선택한 뒤에 부속 이름만 고치는 방식은 사용하지 않는다.
- 표시 캐시가 새 정규화 코드 변경에도 무효화되도록 입력 스탬프에 포함한다.
- `junction_normalization`에 점 별칭과 분할 이력을 남긴다. 최불리 가지치기 전
  정규화된 전체 망을 부속 판정/빨간 점선의 원본 근거로 사용한다.

## 검증 및 한계

대명동 같은 선정 범위: 노즐 30개 및 전체 연결 헤드 109개 유지.
계산 노드/배관은 206/205 → 195/194, 배관표 길이 합은 144.846m → 144.055m.
중복 경로 정리와 실제 접속점 복원으로 길이·손실·번호가 달라질 수 있다.
이전 노즐 표시 간격 수정과 달리 이번 변경은 계산 연결 구조의 수정이다.

B1F도 28개 노즐, 전체 헤드 264개를 유지하며 노드 좌표/표고와 배관의
길이/관경/재질/연결은 기존 재생성 결과와 일치한다. 다만 기존 48번의
명시적 동일좌표 접속은 통합 후 실제 4포트로 드러나므로 자동 티를 확정하지
않고 검토 대상으로 남긴다(P54의 이전 티 등가길이는 자동 확정하지 않음).
이는 크로스를 새로 정의한 것이 아니며, 검토 항목을 해소하기 전에는
최종 계산 입력의 정확성을 승인한 것으로 보면 안 된다.
