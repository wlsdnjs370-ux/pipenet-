1. 문서 목적

본 보고서는 PIPENET 수리계산 검증 프로그램의 2번 메뉴인 「설계 최적화 가이드」가 어떤 입력 데이터를 사용하고, 어떤 수식과 판정 로직을 거쳐 「공학적 마찰손실 최적화 조치」와 「시공사 경제성 확보 방안」을 출력하는지 설명하기 위한 문서이다.

이 기능은 법적 기준을 무시하고 관경을 줄이는 기능이 아니다. 먼저 PIPENET 결과서와 SDF 파일을 기반으로 필수 검증 항목을 확인한 뒤, 그 기준을 만족하는 범위 안에서 공학적으로 안정적인 설계 방향과 경제적으로 과설계를 줄일 수 있는 방향을 분리하여 제시한다.

프로그램은 최종적으로 다음 네 가지를 구분해서 보여준다.

- 법적·기술적 기준을 위반한 즉시 수정 대상
- 공학적으로 손실 집중, 유속 여유 부족, 압력 여유 부족이 의심되는 개선 후보
- 경제적으로 저유속, 과대 관경, 대구경 밸브, CPVC 대구경 등이 의심되는 절감 후보
- 공학 관점과 경제 관점이 서로 충돌하는 절충 검토 대상

2.2 SDF 파일

SDF 파일은 계산값의 원천이라기보다는 배관망 위치와 형상을 시각화하기 위한 원본 네트워크 데이터로 사용된다.

SDF에서 사용하는 주요 정보는 다음과 같다.

- Node 좌표
- Pipe input/output node
- Pipe waypoint
- Nozzle 위치
- Special Equipment 위치
- Valve 또는 감압밸브 위치

SDF 파일은 Friction Loss Spike Map과 Economy Optimization Candidate Map을 생성할 때 사용된다. 단, 후보 판정값 자체는 결과서 DOCX의 FLOW IN PIPES, PIPE CONFIGURATION, SPECIAL EQUIPMENT 등에서 추출된 값을 기준으로 한다.


3. 설계 최적화의 기본 전제

3.1 최적화 전 필수 기준

설계 최적화는 최소 법적 기준을 통과한 이후에 검토되어야 한다. 프로그램은 다음 조건을 최적화 전제로 둔다.

- 헤드 최소 방수압 0.1 MPa 이상 확보
- 헤드 최소 방수량 기준 만족
- 가지배관 유속 6 m/s 이하
- 그 밖의 배관 유속 10 m/s 이하
- 재질별 C-Factor 기준 만족
- 특수설비, 밸브, 감압밸브 등가길이 및 설정값 검증
- Hazen-Williams 공식 기반 마찰손실 재계산 검증

3.2 공학적 최적화와 경제성 최적화의 차이

공학적 최적화는 안정성, 압력 여유, 마찰손실 분산, 유속 안정성을 우선한다.

경제성 최적화는 법적·기술적 기준을 만족하는 범위 안에서 관경, 밸브, 재질, 시공비를 줄이는 방향으로 제안한다.

따라서 경제성 후보가 표시되더라도 즉시 관경을 줄이라는 의미가 아니다. 관경 축소 전에는 반드시 다음 조건을 다시 확인해야 한다.

- 가지배관 유속 ≤ 6.0 m/s
- 그 밖의 배관 유속 ≤ 10.0 m/s
- 말단 방수압 ≥ 0.1 MPa
- 헤드 유량 기준 만족
- Hazen-Williams 재계산상 손실 허용 범위 만족


4. 공통 계산 지표

4.1 m당 마찰손실

m당 마찰손실은 배관 길이가 서로 다른 구간을 동일한 기준으로 비교하기 위한 정규화 지표이다.

수식은 다음과 같다.

m당 마찰손실 = friction_loss / length

여기서,

- friction_loss = FLOW IN PIPES의 Frict. Loss 값
- length = PIPE CONFIGURATION의 Length 값
- 단위 = kg/cm²/m

긴 배관은 총 마찰손실이 자연스럽게 커질 수 있으므로 총 마찰손실만으로는 손실 집중 여부를 판단하기 어렵다. 따라서 단위 길이당 손실을 계산하면 짧은 배관인데 손실이 과도한 구간, 피팅이나 특수설비가 집중된 구간, 유속이 높은 구간을 더 쉽게 찾을 수 있다.

4.2 마찰손실 변화율

마찰손실 변화율은 직전 Pipe와 비교했을 때 m당 마찰손실이 얼마나 급격히 증가했는지를 나타낸다.

마찰손실 변화량 = 현재 Pipe의 m당 마찰손실 - 직전 Pipe의 m당 마찰손실

마찰손실 변화율 = 마찰손실 변화량 / max(직전 Pipe의 m당 마찰손실, 1e-9)

프로그램은 Pipe Label 순서대로 정렬한 뒤, 인접 배관 간 변화를 계산한다.

이 지표는 다음 상황을 포착하기 위한 보조 지표이다.

- 특정 배관에서 갑자기 관경이 줄어든 경우
- 특정 배관에 피팅 또는 특수설비가 집중된 경우
- 유속이 급격히 증가한 경우
- 배관 경로가 급격히 꺾이는 경우

4.3 유속 여유율

유속 여유율은 실제 유속이 해당 배관의 허용 유속 기준 대비 얼마나 여유가 있는지 나타낸다.

유속 여유율 = 1 - actual_velocity / velocity_limit

여기서,

- actual_velocity = FLOW IN PIPES의 Velocity
- velocity_limit = topology 기반 배관 역할 판정에 따른 허용 유속

배관 역할별 기준은 다음과 같다.

- branch: 6.0 m/s
- other: 10.0 m/s

유속 여유율이 0 이상 10% 미만이면 공학적 최적화 후보로 분류한다. 이는 아직 기준을 초과하지 않았더라도 허용치에 매우 근접한 상태이므로, 설계 변경이나 시공 오차에 취약할 수 있기 때문이다.

4.4 압력 여유

압력 여유는 해당 배관 또는 헤드에서 요구 최소 압력보다 실제 압력이 얼마나 높은지를 나타낸다.

압력 여유 = actual_pressure - required_pressure

헤드 기준에서는 required_pressure를 1.0 kg/cm², 즉 0.1 MPa로 본다.

공학 관점에서는 출구압 또는 말단 관련 압력이 1.2 kg/cm² 미만인 구간을 압력 여유 부족 후보로 본다.

경제 관점에서는 헤드 압력이 1.30 kg/cm² 이상인 경우 압력 여유가 큰 후보로 본다. 이 경우 관경 축소 또는 경로 조정을 가정해도 최소 기준을 만족할 가능성이 있어 경제성 시뮬레이션 후보가 된다.

4.5 피팅 및 특수설비 등가길이 비율

피팅과 특수설비는 실제 배관 길이 외에 추가 손실을 발생시킨다. 프로그램은 이 영향을 총 등가길이 대비 비율로 계산한다.

피팅/특수설비 등가길이 비율 = (fitting_eq_length + special_eq_length) / total_length

total_length = base_length + fitting_eq_length + special_eq_length

여기서,

- base_length = PIPE CONFIGURATION의 Length
- fitting_eq_length = PIPE CONFIGURATION의 Fitt.eq.lnth
- special_eq_length = SPECIAL EQUIPMENT에서 동일 Pipe Label에 연결된 Equivalent Length 합계

이 비율이 30%를 초과하면 공학적 최적화 후보로 표시한다. 이는 배관 자체보다 부속 저항의 영향이 상대적으로 크다는 의미이다.


5. 공학적 마찰손실 최적화 조치 로직

5.1 목적

공학적 최적화는 최소 기준 만족보다 더 보수적인 설계를 지향한다. 목표는 다음과 같다.

- 배관망 안정성 확보
- 마찰손실 급증 구간 최소화
- 특정 배관에 손실이 집중되는 현상 완화
- 말단 압력 안정성 확보
- 유속 급변 구간 완화
- 설계 변경 또는 시공 오차에 대한 여유 확보

5.2 공학 후보 분류 기준

프로그램은 다음 조건 중 하나라도 만족하는 Pipe를 공학적 최적화 후보로 분류한다.

5.2.1 마찰손실 후보

조건은 다음과 같다.

m당 마찰손실 > 1.00 kg/cm²/m

즉,

friction_loss / length > 1.00

이 조건에 해당하면 후보 사유는 “마찰손실”로 기록된다.

이 조건은 Friction Loss Spike Map의 빨간색 표시 기준으로도 사용된다. 따라서 Friction Loss Spike Map의 빨간 배관은 공학 후보 전체가 아니라, 오직 m당 마찰손실이 1.00 kg/cm²/m를 초과한 배관이다.

5.2.2 변화율 후보

조건은 다음과 같다.

마찰손실 변화율 > 50%

그리고 동시에,

현재 Pipe의 m당 마찰손실 > 0.10 kg/cm²/m

즉,

(current_unit_loss - previous_unit_loss) / previous_unit_loss > 0.50

and

current_unit_loss > 0.10

이 조건에 해당하면 후보 사유는 “변화율”로 기록된다.

5.2.3 유속 여유 후보

조건은 다음과 같다.

0 ≤ 유속 여유율 < 0.10

즉,

0 ≤ 1 - actual_velocity / velocity_limit < 0.10

예를 들어 가지배관 기준 6.0 m/s에서 실제 유속이 5.95 m/s라면,

유속 여유율 = 1 - 5.95 / 6.00 = 0.0083 = 0.83%

이 경우 기준 초과는 아니지만 허용치에 매우 근접하므로 공학적 최적화 후보로 분류된다.

후보 사유는 “유속여유”로 기록된다.

5.2.4 피팅 집중 후보

조건은 다음과 같다.

(fitting_eq_length + special_eq_length) / total_length > 0.30

즉, 피팅과 특수설비 등가길이가 총 등가길이의 30%를 초과하면 후보가 된다.

후보 사유는 “피팅집중”으로 기록된다.

5.2.5 압력 여유 부족 후보

조건은 다음과 같다.

outlet_pressure < MIN_HEAD_PRESSURE + 0.20

현재 프로그램의 MIN_HEAD_PRESSURE는 1.0 kg/cm²이므로,

outlet_pressure < 1.20 kg/cm²

이면 공학적 압력 여유 부족 후보로 본다.

후보 사유는 “압력여유”로 기록된다.

5.3 공학 리포트 생성 방식

프로그램은 위 조건별 후보를 집계한 뒤 다음 형태로 리포트를 생성한다.

- 후보 유형별 개수
- 주요 구간 Pipe 목록
- 각 Pipe의 핵심 계산값
- 권장 조치

예시 문장은 다음과 같은 구조를 가진다.

- m당 마찰손실 기준 초과 배관이 N개 있습니다. 주요 구간: Pipe 107(...)
- 직전 배관 대비 마찰손실 변화율 급증 후보가 N개 있습니다. 주요 구간: Pipe 52(...)
- 유속 기준 여유가 10% 미만인 배관이 N개 있습니다. 주요 구간: Pipe 113(...)
- 피팅/특수설비 등가길이 비율이 30%를 넘는 후보가 N개 있습니다. 주요 구간: Pipe 5(...)
- 출구압력이 1.2 kg/cm² 미만인 압력 여유 부족 후보가 N개 있습니다. 주요 구간: Pipe 1(...)

프론트엔드는 “주요 구간:” 뒤에 나오는 Pipe 목록을 자동으로 파싱하여 구분, 번호, 판정값 3열 테이블로 표시한다.

5.4 공학 조치 방향

공학 후보가 발생하면 프로그램은 다음 조치를 안내한다.

- 구경 상향 검토
- 피팅 축소
- 특수설비 위치 조정
- 배관 경로 단순화
- 분기 위치 재조정
- 루프 또는 그리드 배관망 검토
- 특정 계통 손실 집중 완화
- 말단 압력 안정성 확보

단, 공학 조치는 일반적으로 비용 증가를 동반할 수 있으므로, 프로그램은 “먼저 피팅과 경로를 점검하고, 그 다음 관경 상향을 검토한다”는 절충 원칙을 제시한다.


6. Friction Loss Spike Map 로직

6.1 목적

Friction Loss Spike Map은 공학적 최적화 후보 중에서도 “마찰손실 급증 전용 구간”만 시각화하기 위한 네트워크 맵이다.

6.2 표시 기준

빨간색으로 표시되는 Pipe 조건은 다음 하나이다.

friction_loss / length > 1.00 kg/cm²/m

중요한 점은 Friction Loss Spike Map은 engineering_flag 전체를 빨간색으로 표시하지 않는다는 것이다.

공학 후보에는 변화율, 유속여유, 피팅집중, 압력여유 등이 모두 포함될 수 있지만, Friction Loss Spike Map의 빨간색은 오직 m당 마찰손실 기준 초과 배관만 의미한다.

6.3 화면 조작

Friction Loss Spike Map은 다음 조작을 지원한다.

- + 버튼: 확대
- - 버튼: 축소
- 마우스 드래그: 화면 이동
- 빨간 배관 위 마우스 이동 또는 드래그: Pipe 정보 툴팁 표시

툴팁에는 다음 정보가 표시된다.

- Pipe 번호
- 마찰손실
- 배관 길이
- m당 마찰손실
- 직전 Pipe 대비 변화율
- 직전 Pipe 번호
- 증가량
- 유속


7. 시공사 경제성 확보 방안 로직

7.1 목적

경제성 최적화는 가능한 싸게 만드는 것이 아니라, 법적·기술적 기준을 만족하는 범위 안에서 과설계를 줄이는 것이다.

주요 목표는 다음과 같다.

- 불필요하게 큰 관경 축소
- 대구경 밸브 비용 절감
- CPVC 대구경 구간 회피
- 압력 여유 과다 구간 활용
- 물량이 많은 가지배관 구간 최적화
- 관경 축소 시뮬레이션 대상 선별

7.2 경제성 후보 분류 기준

프로그램은 다음 조건 중 하나라도 만족하는 Pipe를 경제성 검토 후보로 분류한다.

7.2.1 저유속 과설계 후보

조건은 다음과 같다.

velocity < 2.0 m/s

and

nominal_bore > 25A

즉 실제 유속이 2.0 m/s 미만이고, 구경이 25A보다 큰 경우 과설계 후보로 본다.

후보 사유는 “저유속 과설계”로 기록된다.

7.2.2 주배관 관경축소 후보

조건은 다음과 같다.

pipe_role = other

and

nominal_bore ≥ 80A

and

velocity_margin > 0.35

즉, 주배관 또는 교차배관 계통으로 분류된 배관 중 구경이 80A 이상이고 유속 여유가 35%를 초과하면 관경 축소 후보로 본다.

후보 사유는 “주배관 관경축소”로 기록된다.

검토 방향은 다음과 같다.

- 125A → 100A
- 100A → 80A
- 80A → 65A

단, 축소 후에는 반드시 10 m/s 이하 유속, 말단 방수압 0.1 MPa 이상, 헤드 유량 기준, Hazen-Williams 재계산을 다시 만족해야 한다.

7.2.3 가지배관 관경축소 후보

조건은 다음과 같다.

pipe_role = branch

and

nominal_bore ∈ {32A, 40A, 50A}

and

velocity_margin > 0.35

즉, topology상 가지배관으로 분류된 배관 중 유속 여유가 충분히 큰 경우 관경 축소 후보로 본다.

후보 사유는 “가지배관 관경축소”로 기록된다.

검토 방향은 다음과 같다.

- 50A → 40A 또는 32A
- 40A → 32A
- 32A → 25A

단, 축소 후에는 가지배관 유속 6 m/s 이하와 말단 방수압 0.1 MPa 이상을 반드시 다시 확인해야 한다.

7.2.4 압력 여유 활용 후보

조건은 다음과 같다.

nozzle_pressure ≥ 1.30 kg/cm²

헤드 압력이 1.30 kg/cm² 이상이면 법적 최소 기준 1.0 kg/cm² 대비 여유가 큰 것으로 보고 경제성 시뮬레이션 후보로 본다.

해석 흐름은 다음과 같다.

현재 말단 압력 확인
→ 관경 한 단계 축소 가정
→ Hazen-Williams 재계산
→ 유속 기준 확인
→ 말단압력 0.1 MPa 이상 유지 확인
→ 통과하면 경제성 후보

경제 목표 압력은 보통 1.1~1.2 kg/cm² 수준으로 안내한다. 이는 최소 기준 1.0 kg/cm² 바로 위의 위험한 설계가 아니라 최소한의 여유를 남기는 절충적 경제 설계를 의미한다.

7.2.5 CPVC 대구경 비용 후보

조건은 다음과 같다.

material_name startswith CPVC

and

nominal_bore > 65A

즉 CPVC 배관이 65A를 초과하면 경제성 검토 후보로 본다.

후보 사유는 “CPVC 대구경”으로 기록된다.

검토 방향은 다음과 같다.

- CPVC 80A 이상 단일 라인 회피
- 50A/65A 복수 라인 분산 검토
- 단위세대 인입부 65A 이하 유지 가능성 검토
- 재질 단가와 시공성, 압력손실을 함께 비교

7.2.6 대구경 밸브 비용 후보

조건은 다음과 같다.

valve_connected_bore > 100A

알람밸브, 프리액션밸브, 자동경보밸브 등 밸브 연결 배관 구경이 100A를 초과하면 밸브 단가가 급격히 증가할 수 있으므로 경제성 검토 후보로 본다.

검토 방향은 다음과 같다.

- 수리계산 여유가 있을 경우 100A 이하 조정 가능성 검토
- 밸브실 대구경 밸브 수량 검토
- 대구경 밸브와 연결 배관의 동시 축소 가능성 검토

7.3 경제성 리포트 생성 방식

프로그램은 경제성 후보를 유형별로 집계하고 다음 정보를 표시한다.

- 후보 유형별 개수
- 주요 구간 Pipe 목록
- 구경, 유속, 여유율 등 핵심값
- 관경 축소 또는 비용 절감 검토 방향
- 축소 후 재검증 조건

“주요 구간:” 뒤의 목록은 프론트엔드에서 자동으로 테이블화된다.


8. Economy Optimization Candidate Map 로직

8.1 목적

Economy Optimization Candidate Map은 경제성 후보 배관만 별도로 네트워크 상에 표시하기 위한 맵이다.

공학 맵과 경제성 맵을 분리하는 이유는 다음과 같다.

- 빨간색 공학 맵은 손실 급증과 안정성 측면의 문제를 보여준다.
- 초록색 경제성 맵은 과설계 또는 원가 절감 가능성을 보여준다.
- 두 맵을 나란히 보면 공학적으로 보강해야 할 구간과 경제적으로 줄일 수 있는 구간을 구분할 수 있다.

8.2 표시 기준

초록색으로 표시되는 Pipe는 economy_flag가 true인 배관이다.

economy_flag는 다음 사유 중 하나 이상이 있으면 true가 된다.

- 저유속 과설계
- 주배관 관경축소
- 가지배관 관경축소
- CPVC 대구경

각 Pipe의 세부 사유는 economy_reasons 필드에 기록된다.

8.3 화면 조작

Economy Optimization Candidate Map은 Friction Loss Spike Map과 동일한 조작을 지원한다.

- + 버튼: 확대
- - 버튼: 축소
- 마우스 드래그: 화면 이동
- 초록 배관 위 마우스 이동 또는 드래그: Pipe 정보 툴팁 표시

툴팁에는 다음 정보가 표시된다.

- Pipe 번호
- 마찰손실
- 배관 길이
- 경제성 후보 사유
- 구경 정보
- 유속


9. 결과 데이터 테이블의 후보 사유 필드

프로그램은 각 Pipe row에 다음 필드를 추가한다.

9.1 engineering_reasons

공학 후보 사유를 쉼표로 연결한 문자열이다.

가능한 값은 다음과 같다.

- 마찰손실
- 변화율
- 유속여유
- 피팅집중
- 압력여유

예시는 다음과 같다.

engineering_reasons = \"유속여유, 피팅집중, 변화율\"

이 경우 해당 Pipe는 실제 유속이 기준에 근접하고, 피팅/특수설비 등가길이 비율이 크며, 직전 배관 대비 m당 마찰손실 증가율도 크다는 의미이다.

9.2 economy_reasons

경제성 후보 사유를 쉼표로 연결한 문자열이다.

가능한 값은 다음과 같다.

- 저유속 과설계
- 주배관 관경축소
- 가지배관 관경축소
- CPVC 대구경

예시는 다음과 같다.

economy_reasons = \"주배관 관경축소\"

이 경우 해당 Pipe는 주배관 또는 교차배관 계통이며, 구경과 유속 여유를 고려했을 때 관경 축소 시뮬레이션 후보로 분류된 것이다.


10. 공학 관점과 경제 관점의 충돌 처리

공학 최적화와 경제성 최적화는 항상 같은 방향을 의미하지 않는다.

공학적 관점은 다음을 선호한다.

- 관경 상향
- 유속 저감
- 마찰손실 분산
- 압력 여유 확보
- 피팅 감소
- 루프 또는 그리드 배관망 적용

경제성 관점은 다음을 선호한다.

- 관경 축소
- 대구경 밸브 감소
- CPVC 대구경 회피
- 압력 여유가 과도한 구간의 여유 활용
- 물량이 많은 가지배관의 구경 최적화

같은 Pipe가 공학 후보이면서 경제성 후보일 수 있다. 이 경우 단순 관경 축소 또는 단순 관경 상향이 아니라 다음 절충 검토가 필요하다.

- 관경 축소 전 피팅/특수설비 등가길이 축소 가능성 확인
- 배관 경로 단순화 후 재계산
- 재질 변경에 따른 C-Factor 변화 검토
- 루프/분산 배관으로 유속과 손실을 분산한 뒤 관경 축소 가능성 검토


11. 관경 축소 시뮬레이션의 판단 흐름

경제성 리포트에서 관경 축소 후보가 표시되더라도 즉시 축소하라는 의미는 아니다. 실제 적용 전에는 다음 흐름으로 재검증해야 한다.

1단계: 현재 Pipe의 유속, 구경, 역할 확인

- branch인지 other인지 확인
- 현재 유속과 허용 유속 비교
- 유속 여유율 계산

2단계: 한 단계 작은 관경 가정

예시는 다음과 같다.

- 125A → 100A
- 100A → 80A
- 80A → 65A
- 50A → 40A 또는 32A
- 40A → 32A
- 32A → 25A

3단계: Hazen-Williams 재계산

Hazen-Williams 기반 마찰손실은 다음 경향을 가진다.

마찰손실 ∝ Q^1.85 / (C^1.85 × D^4.87)

따라서 관경 D가 작아지면 마찰손실은 매우 민감하게 증가한다.

4단계: 유속 재계산

유속은 다음과 같이 계산된다.

V = Q / A

A = πD² / 4

관경이 줄어들면 단면적이 감소하고 유속이 증가한다.

5단계: 압력 재계산

축소 후 마찰손실 증가분을 반영하여 말단 압력이 0.1 MPa 이상 유지되는지 확인한다.

6단계: 통과 여부 판정

다음 조건을 모두 만족해야 경제성 후보가 실제 적용 가능 후보가 된다.

- 가지배관이면 V ≤ 6.0 m/s
- 그 밖의 배관이면 V ≤ 10.0 m/s
- 말단 방수압 ≥ 0.1 MPa
- 헤드 유량 기준 만족
- HW 재계산상 결과서 재현 가능 범위 유지


12. 루프/그리드 배관망 검토 로직

프로그램은 루프 또는 그리드 배관망을 직접 자동 설계하지는 않는다. 다만 다음 조건이 관찰되면 루프/그리드 검토 문구를 안내한다.

- 하류 헤드 수가 많음
- 특정 계통에 유량이 집중됨
- m당 마찰손실이 높은 긴 주배관이 존재함
- 말단 압력 편차가 큼
- 관경 상향만으로 해결하면 비용 증가가 큰 경우

루프/그리드 배관망의 공학적 장점은 다음과 같다.

- 유량이 양방향으로 분산됨
- 특정 배관의 마찰손실 집중이 완화됨
- 압력 균등화가 가능함
- 전체 관경 축소 가능성이 생길 수 있음

단점은 다음과 같다.

- 설계 난이도 증가
- 시공 복잡도 증가
- 소규모 단순 구간에는 과도할 수 있음


13. C-Factor 활용 로직

C-Factor는 Hazen-Williams 공식에서 마찰손실을 결정하는 핵심 계수이다.

공식상 마찰손실은 다음 경향을 가진다.

마찰손실 ∝ 1 / C^1.85

즉 C-Factor가 높을수록 같은 유량과 같은 관경에서 마찰손실은 낮아진다.

프로그램의 재질별 기본 기준은 다음과 같다.

- 일반 강관 계열: C = 120
- CPVC 또는 내부 조도 개선 재질: C = 150

C-Factor가 높은 재질은 공학적으로 손실을 줄이는 효과가 있다. 그러나 경제성은 단순하지 않다.

경제적으로 유리하려면 다음 관계가 성립해야 한다.

재질 단가 상승분 < 관경 축소 절감분 + 펌프 양정 절감분 + 시공비 절감분

따라서 C-Factor가 높은 재질은 공학적으로 유리할 수 있으나, 실제 경제성 판단은 재료비, 시공비, 관경 축소 가능성, 압력 여유를 함께 검토해야 한다.


14. 현재 구현의 출력 구조

14.1 공학 리포트 출력

공학 리포트는 다음 항목을 포함한다.

- 최적화 전제 안내
- 공학 관점 설명
- m당 마찰손실 기준 초과 후보
- 직전 배관 대비 변화율 후보
- 유속 여유 부족 후보
- 피팅/특수설비 집중 후보
- 압력 여유 부족 후보
- 절충 원칙

14.2 경제성 리포트 출력

경제성 리포트는 다음 항목을 포함한다.

- 경제성 전제 안내
- 저유속 과설계 후보
- 주배관 관경 축소 후보
- 가지배관 관경 축소 후보
- 헤드 압력 여유 활용 후보
- CPVC 대구경 후보
- 대구경 밸브 후보
- 루프/그리드 검토
- C-Factor 활용

14.3 시각화 출력

시각화는 다음 3개로 구성된다.

- Friction Loss Ratio by Pipe
- Friction Loss Spike Map
- Economy Optimization Candidate Map


15. 해석 시 주의사항

15.1 후보는 확정 지시가 아니다.

프로그램이 표시하는 공학 후보와 경제성 후보는 검토 대상이다. 후보로 표시되었다고 해서 반드시 관경을 키우거나 줄여야 한다는 의미는 아니다.

15.2 경제성 후보는 재계산이 필수이다.

경제성 후보는 현재 설계가 여유가 있어 보이는 구간을 표시하는 것이다. 실제 관경 축소 전에는 반드시 PIPENET 또는 동일한 수리계산 로직으로 재계산해야 한다.

15.3 공학 후보는 비용 영향 검토가 필요하다.

공학 후보는 안정성 향상을 위한 후보이지만 관경 상향이나 루프 구성은 비용 증가를 유발할 수 있다. 따라서 피팅 축소, 경로 단순화, 특수설비 위치 조정 등 저비용 개선안을 먼저 검토한 뒤 관경 상향을 판단하는 것이 바람직하다.

15.4 SDF 맵은 위치 확인용이다.

Friction Loss Spike Map과 Economy Optimization Candidate Map은 SDF 좌표를 기반으로 후보 위치를 표시한다. 계산값 자체는 결과서 DOCX에서 추출된 값을 기준으로 한다.


16. 결론

2. 설계 최적화 가이드는 PIPENET 결과서와 SDF 파일을 기반으로 공학적 안정성과 경제성 검토를 분리하여 제공하는 기능이다.

공학적 마찰손실 최적화 조치는 다음을 중점적으로 본다.

- m당 마찰손실이 큰 배관
- 직전 배관 대비 손실 변화율이 큰 배관
- 유속 여유가 부족한 배관
- 피팅 또는 특수설비 등가길이 비율이 큰 배관
- 압력 여유가 부족한 배관

시공사 경제성 확보 방안은 다음을 중점적으로 본다.

- 저유속 과설계 배관
- 관경 축소 가능성이 있는 주배관 또는 가지배관
- 압력 여유가 과도한 헤드 또는 계통
- CPVC 대구경 구간
- 100A 초과 대구경 밸브 계통

최종적으로 프로그램은 공학적으로 보강해야 할 구간과 경제적으로 절감 가능성이 있는 구간을 동시에 제시한다. 사용자는 두 관점을 비교하여 과도한 안정성 확보로 인한 비용 증가와 과도한 비용 절감으로 인한 안정성 저하 사이에서 현실적인 절충안을 검토할 수 있다.
