# Module H 통합 작업 화면

2026-09-29. 통합 공정에만 적용한 화면 개편입니다. Module F와 결합·역산·SDF 계산 엔진은 수정하지 않습니다.

## 구성

- 상단 작업 도구: 연결 설정, 입력표, 관경·펌프 역산, SDF 출력, 보기.
- 연결 설정: 서버가 반환한 도면별 준비 상태, 급수방식, 통합 실행, 실제 노드·배관·노즐·밸브 개수.
- 연결 검사와 좌표 근거는 접어서 보관합니다. 기준망 변경, 연결 분리 경고는 유지합니다.
- 역산: 대상 준비 → 방식 → 목표 조건. 공급 절점·작동 노즐 및 펌프 상세는 펼쳐 확인합니다. 확인 체크는 자동으로 선택하지 않습니다.
- 출력: 원본/역산 검토안과 표시 좌표를 분리 표시하고, 생성과 다운로드를 구분합니다.

## 경계와 보존 규칙

`module_h_integration.js`는 기존 DOM 컨트롤을 재배치하고 `ModuleHUI` 상태 갱신 시 읽기 전용으로 동기화합니다. 새 계산 API, 자동 통합, 자동 역산, 자동 출력은 없습니다. 기존 버튼 ID, 입력 단위·값, 이벤트 핸들러, Access 진입 조건을 유지합니다.

준비 상태는 `merge/state`의 `ready`를 그대로 표시합니다. 파일 업로드나 화면 방문을 완료로 간주하지 않습니다. 결합 완료에도 **검토 필요**가 표시되며 수리계산 합격으로 표현하지 않습니다. 없는 개수는 0으로 추정하지 않고 `—`로 표시합니다. 여러 계통도는 서버의 `order`대로 표시합니다.

미확정/조건 변경 경고와 역산 결과는 감추지 않습니다. 원본 결합망, 역산 검토안, 출력 좌표 간 구분을 유지합니다. 해당하지 않는 역산 압력 필드는 숨기기만 하고 값을 초기화하지 않습니다.

## 반영과 검증

H의 기존 정적 진입 스크립트가 별도 화면 파일을 불러옵니다. 서버 재시작 없이 새로 연 H 화면에 반영됩니다. 사용 중인 페이지를 강제로 새로고침하거나 저장 기록을 변경하지 않습니다. 기존 작업을 저장한 뒤 새로고침해야 새 화면을 사용할 수 있습니다.

`tests/test_module_h_integration_browser.py`에서 실제 테스트 서버의 통합, 입력표, 준비 상태, 미준비 계통도, 갱신 필요, 분리 경고, 처리 중 잠금, 키보드 및 4개 화면 크기를 검증합니다. 기존 `test_module_h_browser.py`의 역산·별도 SDF 출력·다운로드 검증도 함께 실행합니다. 모든 테스트는 격리된 도면과 편집 기록을 사용합니다.
