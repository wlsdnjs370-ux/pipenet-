## 수정 사항

### 알람밸브 공통점의 막다른 자동 생성관

손질의 알람밸브 픽은 급수 접속점도 겸한다. 제한 전개가 같은 픽을 다시
밸브 도식 생성기로 보내면서 기본 2.5m+0.5m의 막다른 가지를 추가했다.
기기표의 A/V는 이미 담당 헤드가 있는 본관에 실리므로 이 가지는 중복이다.

`apply_vertical`에서 명시적으로 같은 좌표를 가진 급수점/밸브 픽만 분리한다.
계산 회랑에서는 해당 도식 가지를 생성하지 않고 A/V 손실은 본관에 보존한다.
근처의 다른 밸브, 전체망 변환, 원본 손질 데이터와 사용자가 그린 실제 배관은
삭제하지 않는다. 입력 좌표 분리 함수는 `graph/boundaries.py`에서 시험한다.

저장된 대명동 손질본에 같은 최불리 30개를 적용한 전후 재현 결과:
노드 230→228, 배관 229→227, 노즐 30개 유지, 막다른 자동 생성관 2→0.
A/V는 P1에 유지되고 등가길이는 전후 동일한 9.5m다. 이 재현은 저장 손질본의
선정이므로 현재 브라우저의 전체 절점 번호가 그대로라는 뜻은 아니다.

### ‘이음매’의 잘못된 소속 표시

공통점 10을 화면에서 평면도 노드로 칠한다는 이유만으로, 그곳에서 끝나는
원래 계통도 배관까지 ‘이음매’로 재분류했다. 통합 직후 원본 배관별 소속을
기록하고 미리보기에 전달한다. 공통점에 닿는 사실은 별도 `boundary` 표시이며,
원래 계통도/기계실 배관은 소속과 편집 키를 유지한다. 새 배관을 만들지 않는다.

## 계통도 계산값과 표시 방향 — 사용자 승인 4m 가정

원본 HSP 레이어에서 사용자 산출과 길이 23개가 모두 일치하는 경로를 재현했다.
시작점은 (-645097.8040654995, 180030.6808502593), 끝점은
(-660681.0832206832, 136464.4665509026)이다.

r5와 r23의 양 끝 원본 X는 모두 -660681mm다. 즉 원본에서는 수직선이다.
그러나 도면 Y에서 얻은 길이와 층별로 계단식 추정한 표고를 섞어
`sqrt(length²-rise²)`를 수평 길이로 배치하면서 실제로 없는 옆 방향을 만들었다.
r4 또한 원본 수직선인데 같은 층으로 묶여 표고차가 0으로 추정되어 있다.

이것은 공통점 좌표 차이가 아니라 **계통도 표시축과 실제 표고의 해석 충돌**이다.
사용자가 실제 층고를 확인해 재산정하도록 요청했다. 제출용 DXF 3종의 텍스트와
치수 객체를 조사했지만 실제 층고표는 발견하지 못했다. 원본 sample_problem
계통도는 제출용과 SHA256이 같았다. 보관 SDF의 29F/34F/48F/49F 설치 표고도
비교했으나 현재 30F 경로의 실제 층고/접속점 설치높이를 확정할 수 없었다.
사용자는 2026-09-20 "만약없다면 그냥 4m로 그려"라고 가정 적용을 승인했다.

`graph/elevation.py`의 독립된 층 기준 모델과 Module F 어댑터로 다음을 적용했다.

- 층 간격은 4m, 층 사이 노드와 최상층 밖 노드는 인접 층 간격에 비례해 환산.
  **확정 측량값이 아니며** 모든 값에 `user_assumed_floor_height` 출처를 남긴다.
- 알람밸브를 표고 0으로 기준화한다. 도면 X와 Y 원본 좌표는 보존한다.
- 계통도 Y는 Z로만 쓰고, 배관 길이는 X 이동량과 표고차로 재계산한다.
  수직관은 길이=절대표고차이므로 가짜 수평 이동을 만들지 않는다.
- r5는 4m/-4m, r23은 약 4.406m/-4.406m. r4의 잘못된 표고차 0도 해소.
- 같은 층 모드는 기존 동작을 보존한다. 층 표기가 없거나 서로 충돌하면
  임의 환산 대신 명시적인 오류를 반환한다. 확정 층별 표고와 가정을 동시에
  요청해도 거절한다. 기계실 평면 자체의 천장고는 이 가정으로 덮지 않는다.
- 계통도 추출 화면에 가정 층고(m) 입력란(기본 4)과 근거 안내를 추가했다.
  추출 요약 및 통합 단계 기록에 가정값임을 표시한다.
