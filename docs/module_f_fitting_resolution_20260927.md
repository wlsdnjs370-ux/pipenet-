# 수동 부속 확정과 역산 입력 연동 수정

## 재현·원인

- B1F 편집 기록: 평면도 노드 71 / P70에 `ELBOW_90_STD` 지정.
- 직접 편집 부속은 `equipment`에 `editor_node`, `editor_library`로 저장되나,
  역산은 최초 `meta`의 `부속 판정 불가=1`만 검사해 실행을 거부했다.
- 통합 표에는 미확정 위치 상세가 전달되지 않고 건수만 복사됐다.
- 수동 엘보까지 일반 기기로 취급해 관경을 잠갔다. 관경별 등가길이 표가
  있는데도 확대 후보를 만들지 않아, 별도 13헤드 재현망의 P70이 6.67m/s에 머물렀다.
- 통합부가 생성하는 `gate/check/butterfly`와 라이브러리 ID의 연결도 빠져 있었다.

## 변경

- `src/pipenet_converter/graph/fitting_review.py`에서 현재 부속을 대조한다.
  정확한 배관과 끝점에 지정된 엘보/분류티만 해당 미확정을 해소한다.
  인접 부속, 배관 중간 부속, 밸브, 다른 노드는 해소 근거로 삼지 않는다.
- 원래 미확정 행은 보존한다. 삭제·되돌리기 때 다시 미확정이 된다.
  위치 없이 건수만 남은 과거 자료는 차단을 유지한다.
- 통합 시 표시 노드 번호와 충돌로 변경된 배관 이름을 함께 옮긴다.
  원본 엔진의 식별자는 보존한다. 평면도·통합 표시·역산이 같은 판정을 사용한다.
- 라이브러리 기반 수동 부속은 후보 관경별 등가길이를 계산해 한 번만 합산한다.
  관경별 자료 없는 일반 기기는 기존 잠금을 유지한다. 저장 손실과 라이브러리
  손실이 다르면 임의 교정하지 않고 확인을 요구한다.
- 역산 결과창에도 시작 실패 사유와 노드/배관을 표시한다.
- 물흐름·트리/루프 연결·표고·원본 관경·사용자 편집 기록은 변경하지 않는다.

`feasible_review`, 미달 0건. 관경·유량 수치는 원본에 적용하지 않았다.
