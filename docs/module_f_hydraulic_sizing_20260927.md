# 통합 배관 내경 역산 · 필요 펌프 성능 검토

## 사용

통합 결합 → **배관 내경 역산 · 필요 펌프 성능 (검토용)** 열기 → 현재 결합망
불러오기 → 조건·작동 노즐·배관 역할·잠금 확인 → 확인 체크 → 역산 검토안 계산.

세 방식:

1. 공급압력 고정 → 허용 규격으로 관경 확대. 이것은 실제 펌프 곡선 운전점 계산이 아니다.
2. 관경 고정 → 작동 헤드 최소조건을 만족시키는 공급압력 탐색, 필요 Q/H 제안.
3. 관경 확대와 필요 공급압력 탐색 반복. 현재 관경 이상으로만 확대하는 유한 탐색이며
   최소비용/최소관경/전역 최적해 보장은 하지 않는다.

원본 표·아이소·추출망·보통 「산출」은 변경하지 않는다. 결과 표의 배관 번호는 원본
아이소 위치를 선택한다. 별도 검토안 SDF/SLF 및 전체 입력·결과·반복 기록 JSON을 제공한다.
입력 변경 시 재계산, 결합망 변경 시 예전 결과 출력 차단. 슬롯 전환에도 결과는 통합 상태로 유지된다.

## 계산 계약

- 물 20°C, 밀도 998.2 kg/m³, 중력가속도 9.80665 m/s².
- SI Hazen–Williams: h=10.67 L |Q|^1.852 /(C^1.852 D^4.871).
  Q는 m³/s, D는 실제 내경 m. 내부 유량 미지수는 L/s로 단위 변환한다.
- 모든 실제 배관에 부호 있는 에너지식, 모든 내부 절점에 연속식을 동시에 푼다.
  순환 간선·평행관을 삭제하지 않는다. 희소 감쇠 Newton법, 압력 의존 방수 Q=K√P.
- 질량 잔차 ≤1e-6 L/s, 에너지 잔차 ≤1e-5 m를 모두 만족해야 수렴.
  수렴은 설계 조건 충족과 별도이다. 건조 헤드는 방수 0, 음압 절점은 설계 미달.
- 사용자 초기 설정: 최소 80 L/min·1bar, 가지 6m/s·기타 10m/s. 최대 헤드압 기본 12bar,
  공급압 탐색 상한 기본 20bar. 이것은 사용자 검토조건이지 일괄 법규 판정이 아니다.
  헤드 라이브러리 최소/최대압도 함께 검사한다.
- K와 내경은 실제 SLF를 읽는다. 현재 SP-HEAD는 kgf/cm² 기준 K80이라
  bar 기준으로 환산하면 약 80.7848이다. K=80을 무조건 덮어쓰지 않는다.
- 실제 길이·노드 표고·C를 사용한다. 표시용 XY는 수리계산에 사용하지 않는다.
  길이 < 표고차, 분리망, 내경 미상, 비정상 상태, 미확정 부속은 명시적으로 거절한다.
- 헤드는 현재 선정 시나리오 중 사용자가 지정한 노즐만 방수한다. 전체 설치 헤드의
  동시 방수나 전체 건물의 자동 최불리 구역 탐색으로 해석하면 안 된다.

## 부속과 경계

- 부속 합계 캐시 `pipe.eq_len`과 상세 부속을 이중 합산하지 않는다.
- 후보 관경별 라이브러리 등가길이를 다시 조회한다. 직류티는 0(기존 정책 유지).
- 관경별 기기 손실 자료가 없는 배관은 잠금. 손실 미확정은 0으로 보정하지 않는다.
  배관별 전체 등가길이 직접 지정은 모든 부속·기기 손실을 대체하며 관경을 잠근다.
- 루프 분류티는 기존 귀속 배관에 대한 잠정 등가길이 모델이다. 실제 분류/합류의
  유량비별 계수 또는 제조사 손실 특성까지 해석한 모델은 아니다. 결과에 경고를 남긴다.
- 단일 공급 경계 또는 단일 펌프의 토출 이후 망 지원. 다중 펌프, 독립 제어밸브 링크,
  펌프 흡입측 배관까지 포함된 망은 지원하지 않으며 조용히 생략하지 않는다.
- 필요 펌프 양정 = 토출 표고 + 토출 압력수두 + 입력 토출 속도수두 − 입력 흡입 전수두.
  흡입 전수두·토출 속도수두 기본 0은 확인해야 할 가정으로 표시한다.
- Q/H는 한 시나리오의 필요 운전점이다. 제조사 곡선, 모터 정격, 효율, NPSH, 병렬운전,
  정지압/최대압, 다른 구역의 요구 성능 포괄, 설계 여유는 별도 검토한다.

## 출력

조건 충족 검토안만 SDF 출력 가능. 실패는 진단 JSON 제공. SDF는:

- 펌프를 임의 생성하지 않고 계산된 고정 토출압력(절대압 Pa) 공급 경계로 대체한다.
- 모든 물리 배관·길이·표고·관경·C·작동 노즐을 유지한다.
- 계산기와 PIPENET 내장 부속표의 차이를 피하려고 각 배관의 손실을 총 등가길이
  Equipment 하나로 명시한다. 이 별도 검토안에는 원래 부속 심볼을 중복 계상하지 않는다.
  일반 산출의 부속 표시에는 영향 없다.
- 미확정 제목, 동봉 SLF, 계산/입력/경고 JSON을 남긴다. 호칭경뿐 아니라 SLF 실제 내경,
  연결, 길이, C, 공급 경계도 다시 읽어 대조한다.
- 출력의 HW·밀도 설정을 명시하며 오래된 템플릿의 비정상 물성값을 상속하지 않는다.

PIPENET GUI에서의 재계산 및 실제 프로젝트 결과 대조는 아직 완료하지 않았다.
공식 구현과 반올림/계수 관례도 대조해야 하며 인증된 계산서로 사용하면 안 된다.

## 검증

`python -m pytest tests/unit/test_hydraulic_sizing.py tests/test_module_f_sizing.py tests/test_module_f_sizing_browser.py`

손계산 가능한 직렬관, 동일 저항 평행관, 그리드의 0 유량 교차관, 역방향 정의,
K 변화, 과압, 유속 확대, 잠금, 실패/중지, 원본 불변, 오래된 검토안 차단, SDF 왕복 및 실제 UI.

`python scripts/audit_hydraulic_sizing.py --b1f`

- 625 절점·1,200 배관·576 순환·25 작동 헤드: 6번 관경 반복, 약 5초 (개발 PC).
- B1F 저장 13헤드 선택: 215절점·218배관·4순환. 부속 미확정 1건 때문에 계산 차단.
  검증용으로 미확정을 없애거나 손실 0을 가정하지 않았다.
- 상세 결과: `outputs/module_f_hydraulic_sizing_20260927/verification.json`.
- 신규 기능·통합·추출·부속 UI·세션/중지·기존 SDF writer를 함께 실행한 최종 회귀:
  **136 통과, 2개 선택 실행 시험 제외**. B1F 읽기 전용 감사는 위 별도 명령으로 실행했다.
- 실제 백그라운드 작업/중지 미들웨어 시험에서 큰 CAD 객체 복사를 금지하는 표본으로
  정상 실행을 확인했다. 역산은 동기 작업 초안이 아니라 결과 키 2개의 복구 스냅샷을 사용한다.

알고리즘 참고: [EPANET 수리해석 알고리즘](https://epanet-manual.readthedocs.io/en/latest/analysis_algorithms.html).
기존 `core/hydraulic_solver.py`의 트리 유량 누적기는 수정하거나 재사용하지 않았다.
