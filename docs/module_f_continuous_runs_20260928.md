# Module F 연속관 통합 — 2026-09-28

## 범위

기존 `compact_export`는 SDF 복사본만 정리했으므로 화면 선택·직접 편집·입력표는
분절된 상태였다. 이제 평면도 **표 확정**, 통합 **결합** 시 기존 편집 기록을
복원한 다음 실제 편집망을 정리한다. 원본 DXF/손질판을 삭제하거나 재추출하지 않는다.

예: `121 — P129 — 130 — P136 — 137`에서 130이 부속/분기가 없는 직선 중간점이고
두 관의 물성이 같다면 `121 — P129 — 137` 한 배관이 된다.
이는 예시이며 현재 도면의 130번이 해당 조건인지 번호만으로 단정하지 않는다.

## 보존 조건

- 같은 재질, 호칭경·명시 내경, C값, 조도, 상태 등 물성인 연속 직선만 통합한다.
- 실제 연결 차수가 2이고 기준 방향이 이어져야 한다. 반대 기준 방향은 자동 반전하지 않는다.
- 분기/루프 접속, 헤드 및 접속관, 굴곡·수직 전환, 관경 변경, 급수원·펌프·밸브,
  부속 설치점, 미확정 검토점은 보존한다. 위치를 모르는 부속의 호스트 구간도 보존한다.
- 직접 생성·분할한 노드와 그 참조점은 다음 편집 작업을 위해 남긴다.
- 좌표로 길이를 다시 재지 않는다. 선언 길이 및 손실 합산, 남은 노드의 표고 보존.
- 고리를 트리로 자르지 않으며 병렬 간선으로 바뀌는 축약도 하지 않는다.
- 통합에서는 평면도의 정리 결과를 그대로 가져온다. 평면도 ID, 도면 간 접속점,
  평면·아이소 투영에서 꺾이는 점을 보호하며 다른 도면의 구간과 합치지 않는다.
- 엄격한 직선 조건 때문에 좌표 반올림으로 미세하게 꺾인 곳, 물성이 누락되거나
  알려지지 않은 속성이 서로 다른 곳은 남을 수 있다. 임의 허용오차로 지우지 않는다.

## 편집 및 저장

`compact_runs` 버전 1 명령으로 정리한다. 자동 정리도 기존 편집 기록 뒤에 한 단계로
기록하고 되돌리기/다시 실행/동일 기준망 재개방에서 같은 결과를 재현한다.
기존 명령은 분절된 원래 ID로 먼저 실행하므로 사용자의 이전 수정이 사라지지 않는다.
다시 실행할 기록이 남아 있으면 자동 정리를 보류하고 안내한다. 기록을 버리는
새 편집 분기는 기존 편집기의 명시적 적용 절차를 따른다.

화면 아래 **연속관 정리**로 기존 망도 미리보기→개수 확인→확정할 수 있다.
통합에서 평면도에 정리할 구간이 있으면 평면도 원본 편집망을 정리하고 다시 결합한다.
평면도 정리가 끝나 있으면 통합의 계통도·기계실 쪽을 정리한다.
관경을 바꿔 새로 같은 관경이 된 인접 구간도 이 버튼으로 다시 정리할 수 있다.
수동 분할점을 매 편집마다 자동으로 지우지는 않는다.

선택된 통합 배관의 재질/관경 변경은 그 연속 구간 전체에 적용된다. 원본 구간별
관경 근거는 속성 카드의 **통합 전 구간·관경 근거**에 남는다. 서로 다른 근거를
도면 확정값으로 바꾸지 않으며 검토용 미확정 색상/상태를 유지한다.
과거 단일 CAD 선분의 수정 키는 통합 구간의 키로 재사용하지 않는다.

일반 평면도·통합 SDF는 이 편집망을 다시 축약하지 않으므로 화면과 동일한
배관 ID/연결/길이를 쓴다. 되돌리기 또는 직접 분할도 SDF에 그대로 반영된다.
역산 검토안은 별도 후보망이며 제안 관경 적용 후의 별도 출력 정리는 계속 유지한다.
이전의 PIPENET 표시 좌표 4배 확대(상대 기호 크기 축소)는 유지한다.
