# Module F 관경 근거 표시

## 적용 범위

4. 수리계산의 계산망/아이소매트릭 및 통합 배관망에서 기본으로 표시한다.
`관경 근거 표시`를 끄면 기존 배관망 스타일로 돌아간다. 색상 토글은 계산값을 바꾸지 않는다.

| 색 / 선 모양 | 뜻 |
| --- | --- |
| 형광 청록 실선 | 도면 문자값을 참조한 자동 관경 |
| 주황 점선 | 기존 코드의 규약 표로 보완한 관경 |
| 보라 혼합 점선 · ! | 동일 관로 전파 추론, 문자 소속/관경 경계 충돌, 방향 미확인, 상하류 표기 역전, 규약 상향 또는 통합 보정 |
| 회색 점선 | 배관별 출처 미기록. 규약 적용이나 도면 표기 없음으로 단정하지 않음 |
| 흰 마름모 | 사용자가 수정한 배관. 색상은 최초 산정 출처/검토 상태를 보존 |

배관을 클릭하면 현재 호칭경, 원본 문자값·CAD 위치·거리, 코드의 규약값·담당 헤드 수,
보완/보정 사유, 최초 자동값과 최근 사용자 수정 메모를 표시한다.
`관경·재질 바로 수정`은 기존 배관 편집기를 사용하며, 라이브러리 내경과 C값 적용,
망·표·산출 데이터 갱신, 되돌리기/다시 실행 및 기존 편집 기록 저장 경로를 그대로 사용한다.

## 위상 기반 문자 대응 (2026-09-23)

수리계산 표를 다시 확정하면 다음 순서로 계산한다.

1. 기존 문자 후보를 유지하면서 원본 DXF의 TEXT/MTEXT/블록에서 회전 방향을 보완한다.
   OCR 또는 인접한 임의 도형을 리더선으로 추측하지 않는다. 캐시·DXF는 읽기만 한다.
2. 최불리 선정 전 전체 물흐름망과 원본 배관 연결을 대조한다. 교차하더라도 연결되지 않은
   관로나 평행한 다른 관로로 표기를 복사하지 않는다.
3. 후보 관로의 방향과 문자 방향을 대조해 표기 소속을 결정한다. 예를 들어 가로 주관에
   가까운 세로 '25'라도 세로 가지가 대응하면 그 가지의 근거로만 사용한다.
4. 명시 표기 없는 구간은 같은 연결 직선 관로에서만 제한 거리 내 전파한다. 밸브·수원,
   굴절, 다른 관로, 다른 관경 표기 사이의 불확실한 경계를 넘겨 확정하지 않는다.
   직선 관로 중간의 헤드 접속점은 주관을 끊는 경계가 아니다.
5. 전파값, 방향 미확인, 상류보다 하류 표기가 커지는 경우는 보라색 검토로 표시한다.
   상하류 관경 역전은 경고이며 자동 증경으로 지우지 않는다.
6. 한 계산 배관에 서로 다른 관경 표기가 섞이거나 문자 소속을 구분할 수 없으면 임시
   규약 보완값과 후보를 보여주되, 확인 전 파일 산출은 보류한다. 사용자가 필요시 구간을
   나누고 관경을 직접 확인·수정하면 진행한다. 근거·편집 이력은 남긴다.

`configs/diameter_inference.json`에 탐색 거리(mm), 평행/직선 허용각(°), 소속 판정 여유(mm),
최대 전파 거리(mm)를 둔다. 특정 도면명이나 배관 번호로 분기하지 않는다.
속성 카드에는 판정 방식, 전체 담당 헤드, 문자 방향, 제외된 가까운 문자, 충돌 후보와
검토 사유를 추가한다. `design.bore_inference`에 방향 보완 상태와 집계가 기록된다.

핵심 로직: `src/pipenet_converter/graph/diameter_inference.py`.
원문자 보완: `src/pipenet_converter/dxf/diameter_annotations.py`.
서버 연결: `routes/module_f/bore_context.py`.
산출 검증: `src/pipenet_converter/validate/diameter_evidence.py`.

## 이번 변경에서 하지 않은 것

- 관경 선정식과 화재안전기준의 적합성을 변경하거나 새로 검증하지 않는다.
- 위상 정보가 없는 기존 다른 호출자는 기존 최근접 매칭을 유지한다. Module F의 새 표는
  위상 판정 실패 시 최근접 매칭을 재시도하지 않는다.
- 다른 반복 가지의 대표 표기, 리더선, 임의의 영역 표기 해석은 아직 구현하지 않았다.
  동일 직선 관로 전파도 설계자가 확인할 추론이지, 범위를 확정한 결과가 아니다.
- 서로 다른 관경이 만나는 위치를 임의로 생성하거나 배관 길이·좌표를 바꾸지 않는다.
- `text`는 도면 문자를 참조했다는 뜻이지, 올바른 배관에 연결됐다는 보증이 아니다.
- 기존 코드는 도면 문자값이 규약값보다 작으면 상향한다. 이를 `nfpc_min` 검토 상태로 드러낸다.
- `dia` 및 근거값은 **호칭경 mm**다. 실제 내경은 별도의 `inner_mm` 및 재질 라이브러리 값이다.
- 최불리 경로의 빨간 전체 점선은 근거 표시를 끄면 다시 나타난다. 부속류의 빨간 점선은 유지한다.
- SDF의 표시 방식 자체는 변경하지 않는다.

## 데이터 흐름과 호환성

`bore.decide_bores` → `Bores.evidence` → 배관 표 `bore_provenance`
→ 평면/통합 preview `bore_info` → 공통 화면 모듈 `module_f_bore.js`.

기존 `(관경, 출처)` 반환값을 유지하며 추가 정보만 부착한다. 상세 정보가 없는 이전 표는
`dia_src`로 구분하되, 문자값/위치가 없으면 미기록임을 명시한다. 자동 경로의 출처 미기록 값은 회색이다.
새 표 확정 이후부터 상세 근거가 기록된다. 표시 정보만 추가돼도 기존 편집 기록을 잃지 않도록
기준망 식별자에서는 `bore_provenance`만 제외하며, 수리계산 필드는 계속 비교한다.

공통 근거 함수는 `src/pipenet_converter/graph/bore_provenance.py`에 있으며 관경을 결정하지 않는다.
수정 이력의 전체 순서는 기존 편집 기록에, 속성 카드용 최초/최근 근거는 배관에 보존한다.

## 검증

`tests/test_module_f_bore_provenance.py`: 기존 관경 선택 불변, 근거 분류, 사용자 수정,
통합 보정, 편집 기록 호환, 평면/통합 API 근거 전달.

`tests/test_module_f_bore_provenance_browser.py`: 실제 화면·격리된 서버에서 범례 토글,
속성 카드, 바로 수정, 되돌리기/다시 실행, 통합 편집, 미확인/보정 상태 구분.
라이브 서버 세션 또는 사용자 도면을 수정하지 않는다.

`tests/test_module_f_diameter_inference.py`: 세로 25/가로 주관 분리, 회전 불변성,
연결된 주관 전파와 밸브/굴절 경계, 평행 관로 충돌, 상하류 역전 경고,
DXF 방향 보완, 직접 수정과 산출 보류, 파일 미생성.

`tests/test_module_f_diameter_real_drawings.py`: `MODULE_F_REAL_BORE_CHECK=1`로 실행하는
읽기 전용 실도면 점검. 현재 캐시가 없으면 건너뛰고 사용자 캐시를 재생성하지 않는다.
B1F 저장본의 원문자 (753168.48, 210366.11) '25'와 13개 헤드 담당 주관을 대조했다.
주관은 해당 25를 제외하고 같은 관로의 65 전파 추론으로 처리된다. 원본 좌표·연결·선언
길이를 변경하지 않는 것도 검사한다. 대명동은 유효한 현재 캐시가 없어 별도 재검증이 필요하다.
