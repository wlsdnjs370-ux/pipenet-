# Module F 수리계산 미리보기 표시 통일

2026-09-20 사용자 요청: 4단계 아이소매트릭을 손질 단계의 최불리망과 같은
디자인으로 표시하고, 상향식·하향식은 삼각형 방향으로 구분한다.

## 변경 범위

- 기본 배관은 흰색이며 담당 헤드 수에 따른 굵기·밝기를 손질 화면과 공유한다.
  `static/module_f.js`의 `corridorAppearance()`가 두 화면의 공통 기준이다.
- 최원 경로는 손질과 같은 빨간 점선이다. 선택 중에는 배경 망과 함께 흐려지고
  표에서 직접 강조한 배관은 기존 주황색 강조를 유지한다.
- 헤드는 상향 △ / 하향 ▽로 표시한다. 기본 헤드는 흰색, 기준 헤드는 조금 큰
  빨간 삼각형이며 기존 기준 헤드의 이중 원은 수리계산 보기에서 제거한다.
- 방향은 기존 미리보기 응답의 `up` 값을 그대로 사용한다. 화면 좌표의 위아래로
  방향을 재추정하지 않는다. 급수원·밸브는 기존 손질 팔레트의 사각형으로 표시한다.
- 관경 근거 색상·점선은 삭제하지 않고 기본 꺼짐으로 변경한다. 사용자가
  '관경 근거로 색 나누기'를 켜면 이전 진단 색상을 볼 수 있다.
- 투영 좌표, 교차부의 끊어 그리기, 길이·관경·표고, 선정, 그래프 연결 및 파일
  출력 코드는 변경하지 않는다. 실제 노드 클릭의 선택 강조는 유지한다.

## 검증

`tests/test_module_f_design_style_browser.py`는 독립 브라우저에서 실제 화면 코드를
실행해 손질/설계의 배관 스타일 일치, 삼각형 방향, 선택 강조, 진단 색 전환,
교차부 표시, 데이터 불변을 확인한다. 두 투영 모드의 실제 Flask 미리보기 응답도
확인한다. 사용자 세션이나 실도면은 수정하지 않는다.

화면 파일만 바뀌므로 서버 재시작은 불필요하다. 템플릿의 정적 파일 버전을 올렸고,
페이지를 다시 열거나 새로고침하면 적용된다. 생성된 SDF/KFP/HAS 파일의 내부 화면
스타일을 바꾸는 작업은 이번 범위가 아니다.
