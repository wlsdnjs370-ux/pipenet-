# 모듈 F 배관망 직접 편집

적용 대상: 로컬 서버의 **04. 수리계산**, **통합/결합**. 원본 DXF와 손질 단계의 최불리 선정은 보존하고, 확정한 계산 배관망을 편집한다.

## 사용

1. 화면 아래 **배관망 편집 시작**을 누르면 계산망 보기로 전환한다. 노드를 클릭하면 그 위치에 ±X·±Y·±Z 화살표가 나타나며, 배관을 클릭하면 배관만 강조된다.
2. 화살표를 누르고 길이·재질·관경을 정한 뒤 **Enter / 확정**으로 추가한다. 기본 제원은 접속 배관에서 가져온다. **미리보기**는 선택 사항이며, 확정 시에도 서버에서 먼저 검증한다.
3. 추가 후 새 끝 노드에 화살표가 나타난다. 줌은 유지하고, 끝점이 화면 밖에 있으면 화면 위치만 이동한다. Esc는 열려 있는 메뉴·편집 창·위치 선택을 취소한다.
4. **Ctrl+Z**, **Ctrl+Shift+Z** 또는 화면 아래 버튼으로 되돌리기·다시 실행한다. 입력칸에서는 글자 편집 단축키를 유지한다.

| 선택 | 가능한 작업 |
|---|---|
| 노드 | ±X/±Y/±Z 방향 배관·끝 노드 추가, 기존 노드 연결, 헤드 설치·방수량 변경, 일반 노드로 전환 |
| 배관 | 길이 변경과 하류 망 이동, 거리/도면 클릭으로 분할, 재질·관경 변경, 부속·밸브 추가, 추가 부속 제거, 관말 삭제 |

## 우클릭 메뉴

- 노드: **노드속성 변경**(일반 노드, 헤드, 부속/밸브), **세부속성 변경**(실제 XYZ, m), **노드 → 노드 연결**, **복사**, **자르기**, **삭제**, **노드 삭제(배관 합치기)**, **붙여넣기**, **45° 대각 화살표**.
- 배관: **배관속성 변경**, **배관길이 변경**, **배관 분할**, **부속/밸브 추가·제거**, **배관 삭제**.
- 속성은 선택 지점 옆의 작은 창에서 수정한다. 기존 카드 테이블을 펼칠 필요가 없다. 통합 화면도 같은 조작을 사용한다.
- 복사는 선택 노드와 접속 배관 **1개**(들어오는 배관 우선)를 새 가지로 만든다. 다른 시작 노드에서 붙여넣기를 선택해 방향과 길이를 정한다. 원래 배관의 부속·밸브 손실, 선택 노드의 헤드 제원을 복사하며 새 라벨을 부여한다. 전체 하류 망 복사는 아니다.
- 자르기는 관말에만 가능하며, 붙여넣기를 **확정할 때** 원본을 제거한다. 취소하면 원본은 그대로다. Ctrl+C/X/V도 동일하게 동작하며 입력칸에서는 기본 글자 편집을 유지한다.
- 도면·편집 범위가 달라졌거나 복사 후 망이 바뀌면 다시 복사해야 한다. 다른 도면의 라벨을 우연히 참조하지 않는다.
- 배관 합치기는 동일 제원의 일직선 배관 2개 사이 일반 노드에 한정한다. 길이·손실·기기 위치를 보존한다. 급수원·이음매·분기점·헤드·해당 위치의 부속은 합칠 수 없다.
- 삭제는 관말 배관/노드에 한정한다. 적용 불가능한 메뉴는 이유와 함께 비활성화하며, 서버도 같은 조건을 다시 검사한다.
- **45° 옵션은 화살표 표시각만 변경한다.** 실제 배관은 ±X/±Y/±Z 축 방향으로 생성한다. 임의의 대각 배관 생성 기능이 아니며 K-Solver 축 정렬 조건을 유지한다.

기존 노드는 목록 또는 **도면에서 연결할 노드 찍기**로 고른다. 분기는 기존 배관을 분할한 뒤 생긴 노드에서 추가한다. 상·하향 헤드는 접속관을 +Z/−Z로 추가한 후 그 끝에 설치한다. 새 분기와 꺾임에 필요한 부속은 배관을 선택해 명시적으로 추가한다.

## 라이브러리와 출력

- 재질·호칭경·내경·조도: 기존 `kfp_sdf_converter`가 해석하는 권위 SLF. 현재 파일은 `assets/2. Pipenet_hand_FX28.slf`이며 화면에도 출처를 표시한다. SDF가 지원하는 관종/관경과의 교집합만 제공한다.
- 부속·밸브: `cad_project_editor_g/fittings_library_v3.json`. 해당 관경의 등가길이가 없는 항목은 적용을 거절한다. 임의의 0이나 유사 관경으로 대체하지 않는다.
- 추가한 부속은 위치·개수·등가길이를 가진 기기 행이다. SDF에는 Equipment, KFP에는 해당 배관의 추가 등가길이로 들어간다. 기존 자동 부속과 중복 기록하지 않는다.
- 수정된 표와 KFP 노드/배관 메타데이터를 함께 갱신하고 이전 다운로드 경로를 무효화한다. 기존 **수리계산 입력 변환 / 통합 산출**을 다시 실행하면 최신 파일이 생성된다.
- 통합 화면의 평면도 요소는 원래 평면도에 반영한 뒤 통합망을 다시 만든다. 기존 통합 편집은 새 기준망 위에 재적용한다. 새 노드·배관·기기 라벨이 겹치면 생성 순서별 대응으로 참조를 함께 옮긴다. 실제로 원본 요소가 사라지거나 새 교차가 생기는 경우에만 해당 편집 번호와 이유를 알리고 전체 변경을 취소한다. 직접 지정한 관경·내경 쌍은 결합의 기본 관경 정규화가 덮어쓰지 않는다.
- 통합의 되돌리기/다시 실행은 평면도와 통합 편집을 합친 실제 작업 순서를 따른다. 새 편집을 확정하면 두 화면의 미실행 다시 실행 분기를 모두 비운다. 평면도 변경으로 두 기록 파일을 갱신하다 실패하면 앞서 쓴 파일과 메모리도 복원한다.

## 통합 속성 카드와 참조 밑그림

- 통합에서 노드·배관 클릭 시 우측 하단에 속성 카드가 열린다. 배관은 도면 출처·재질·내경·호칭경·길이·C 값, 노드는 표고·역할·연결 배관을 표시한다. 속성 수정은 기존 우클릭 메뉴/방향 화살표를 사용한다. 보기 전환 뒤에도 존재하는 선택은 유지한다.
- **배관 밑그림 깔기** 아래 평면도·계통도·기계실 체크박스로 함께 또는 각각 표시한다. 활성 슬롯과 무관하게 각 슬롯의 원도면 도형을 읽는다. 기준점이나 도형이 없는 슬롯은 사유와 함께 비활성화한다.
- 각 밑그림의 원도면 범위에 1% 여백을 둔 흰색 점선 테두리를 함께 표시한다. 테두리는 도면과 같은 이동·배율·투영을 따르고, 확대·축소에도 선 굵기와 점선 간격은 일정하다. 밑그림을 숨기면 해당 테두리도 숨긴다.
- 표시 중인 밑그림 테두리끼리 겹치는 화면 영역에는 회색 점선 경계를 추가한다. 실제 3D 배관의 교차·접속 판정이 아니며, 확대·축소해도 점선 간격이 일정하다. 해당 도면을 숨기면 겹침 경계도 사라진다.
- 평면도는 원도면 원점 변환, 기계실은 결합 때의 접속점·배율을 사용한다. **계통도는 알람밸브를 고정하고 펌프 높이에 맞춰 균등 확대·축소하며 수직선의 기울기를 없앤다.** 원도면의 두 기준점에 가로 간격이 있으면 양끝을 모두 일치시키는 대신 그 간격을 보존한다. 같은 높이의 기준점은 거리 비율로 배율만 정한다. 통합 입상관은 균등 간격으로 재배치하므로 중간 경로와 원도면이 완전히 일치하지 않을 수 있다. 좌표를 수리계산망에 쓰거나 그림으로 접속을 추정하지 않는다.
- 원도면 선분·원·원호는 최초 표시 때만 전송하고 브라우저 Path2D를 재사용한다. 개별 표시 토글은 통신·추출 없이 그리기만 바꾸며 줌을 유지한다. 기존 원도면 미리보기의 도형 상한은 그대로 적용된다.

## 좌표와 기록

- 편집 코어의 XYZ와 길이는 m이다. 표의 XY mm / 표고 m 변환은 어댑터에서만 수행한다.
- 축 방향 추가는 해당 좌표 하나만 바꾼다. 다른 축을 격자로 반올림하지 않는다.
- 원본 시스템 도식의 표시 길이와 계산 길이가 다를 수 있어 기존 배관 길이를 좌표로 일괄 재계산하지 않는다. 분할은 명시 길이를 비율로 나누며, 연장은 선택한 배관의 길이만 바꾼다.
- 같은 높이의 새 교차·겹침, 중간 노드 통과, 새 단절, 루프·급수원·펌프·이음매를 이동시키는 연장을 거절한다. 교차는 먼저 분할하고 명시적으로 연결한다.
- 헤드는 한 배관으로 연결된 관말에만 설치한다. 기존 헤드에서 연장하려면 일반 노드로 전환한다.
- `data/network_editor/`에 도면 키를 해시한 JSON 기록을 원자적으로 저장한다. 기준 망 전체 지문과 라이브러리 지문이 같을 때만 재생한다. 다른 창의 저장 충돌, 바뀐 도면에 대한 이전 라벨 재사용은 거절한다.
- **표 확정**과 **결합**은 기존 편집 기록 때문에 차단하지 않는다. 추출이 성공한 뒤 기준망과 라이브러리 지문이 같으면 기존 편집을 재생한다. 기준이 달라졌으면 기존 JSON의 바이트를 `data/network_editor/archive/<도면·범위 해시>/`에 먼저 보관하고 새 표를 사용한다. 같은 기준망으로 다시 확정하면 보관된 해당 기록을 복원한다. 저장된 다른 망의 라벨을 새 망에 임의 적용하지 않는다.
- 보관 기록은 **편집 기록** 창에서 명령·적용 개수·보관 파일 경로를 확인할 수 있다. 백업이나 저장이 실패하면 이전 기록을 덮어쓰지 않는다. 표를 확정하지 않은 상태에서 망이 예기치 않게 바뀌는 경우에는 기존 충돌 검사를 유지한다.
- Working 취소가 최종 저장과 겹치면 메모리와 해당 JSON 저장본을 함께 복원한다.

## 기본 화면 정리

- 도면 열기의 이어서 열기와 정상 자동 인식 안내 문장은 표시하지 않는다. 오류·주의 메시지는 계속 표시한다.
- 찍기의 인식 결과·낮은 신뢰도 선택은 **자동 추천** 안에 묶는다.
- 손질의 **상태**, 수리계산의 **계산 상세·진단**과 **관경 근거·제외 사유**, 입력 변환의 **전개 설정**은 처음에는 접혀 있다. 제목을 클릭하거나 키보드 Enter/Space로 펼친다.
- 숨김은 화면 구성에만 적용한다. 입력값·체크 상태·표 확정·변환 로직과 상세 정보를 다시 보는 기능은 유지한다.

## 검증

표 재확정 회귀는 `tests/test_module_f_editor_rebuild.py`에서 같은 기준망의 편집 재생, 다른 망 기록의 원본 보관과 복원, 백업 실패·취소 처리, 실제 표 확정 → 미리보기 → 파일 생성 경로를 확인한다. 기본 화면과 접기 동작은 `tests/test_module_f_quiet_ui_browser.py`에서 실제 브라우저로 확인한다.

회귀 검사는 `tests/test_module_f_network_editor.py`, `tests/test_module_f_direct_editor.py`, 실제 브라우저/Flask 검사는 `tests/test_module_f_network_editor_browser.py`에 있다. 기존 줌·취소·KFP·통합 검사도 실행한다. −Y 3m 추가의 XYZ·아이소 투영·KFP 일치, 합치기/삭제의 undo, 클립보드 손실 복사, 통합/원본 동기화, 계통도 +Z 추가와 분할 표시를 확인한다.

실제 **B1F 현장조사 소화설비 평면도_컨셉2**의 독립 작업 복사본에서 분할 → +Z 0.75m 추가 → CPVC2 25A → 엘보 → 헤드 추가 → KFP/SDF/SLF/HAS 생성까지 검증했다. 59노드/58배관/10헤드에서 61노드/60배관/11헤드가 되었으며 새 관은 내경 28.02mm, C=150, 등가길이 0.6m를 가진다. 결과: `data/network_editor_validation/b1f_result.json`.

설치된 K-Solver/PIPENET GUI에서의 직접 조작 시험은 이 검증에 포함하지 않는다. 프로그램 내부의 수리계산 실행과 현장 설계 검토는 별도다.
