    작업

    도면을 선택한 뒤 열기를 눌러 새 DXF를 불러올 수 있습니다.

    저장·공유 안내

    저장 도면은 F와 공유합니다. 같은 도면의 동시 편집은 피해주세요. 이 화면 변경은 저장된 도면·편집 기록을 삭제하지 않습니다.

    현재 작업 위치

    기존 처리 순서와 진입 조건을 유지합니다. 현재 위치는 검증 완료를 뜻하지 않습니다.

    최근 안내

    행을 선택하면 해당 배관·노드의 속성을 확인할 수 있습니다. 수치는 원래 입력표 그대로입니다.

    기본 표시는 소수 셋째 자리까지입니다. 원래 값은 마우스를 올리거나 상세 열에서 확인하세요. 계산·출력 값은 바꾸지 않습니다.

    보기·좌표 안내

    평면 보기는 화면만 바꿉니다. 투영·고도 펼침·캔버스 크기는 SDF 표시 좌표에도 적용됩니다. 실제 길이·표고와 구분됩니다.

    원본 결합망 출력입니다. 역산 검토안은 「관경·펌프 역산」에서 별도로 출력합니다.
